# LC 3832. Find Users with Persistent Behavior Patterns

> Hard · [LeetCode](https://leetcode.com/problems/find-users-with-persistent-behavior-patterns/) · Tags: —

## 题意

找出存在至少 5 天「每天恰好同一动作」连续 streak 的用户；每人保留最长 streak。

## 最优思路

过滤一天多动作；date−row_number 分组连续段，聚合后取每人最优 streak。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```
