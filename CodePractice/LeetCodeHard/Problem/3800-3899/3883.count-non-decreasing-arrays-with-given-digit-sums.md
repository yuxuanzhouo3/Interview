# LC 3883. Count Non Decreasing Arrays With Given Digit Sums

> Hard · [LeetCode](https://leetcode.com/problems/count-non-decreasing-arrays-with-given-digit-sums/) · Tags: Array, Dynamic Programming, Prefix Sum

## 题意

给定 digitSum。求有多少个非降数组 arr（0≤arr[i]≤5000）满足 arr[i] 的数位和等于 digitSum[i]，答案取模 1e9+7。

## 最优思路

预处理每个数位和对应的候选数；按位置 DP，转移到不小于上一个值的候选。候选有序，用前缀和加速转移。
