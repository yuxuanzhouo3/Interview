# LC 3924. Minimum Threshold Path With Limited Heavy Edges

> Hard · [LeetCode](https://leetcode.com/problems/minimum-threshold-path-with-limited-heavy-edges/) · Tags: Binary Search, Breadth-First Search, Graph Theory

## 题意

无向带权图，阈值以下为轻边、以上为重边。求最小阈值使 source 到 target 存在至多 k 条重边的路径。

## 最优思路

对阈值二分。轻边并查集合并成连通块，重边在块之间建图，从起点块做至多 k 层 BFS。
