# LC 3985. Palindromic Subarray Sum

> Hard · [LeetCode](https://leetcode.com/problems/palindromic-subarray-sum/) · Tags: Array, Binary Search, Hash Function, Prefix Sum

## 题意

求 nums 中回文子数组的最大和。

## 最优思路

在元素间插入分隔符后跑 Manacher，用前缀和取每个回文半径对应区间和的最大值。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```
