# LC 3981. Count Distinct Ways to Form Target from Two Strings

> Hard · [LeetCode](https://leetcode.com/problems/count-distinct-ways-to-form-target-from-two-strings/) · Tags: String, Dynamic Programming, Prefix Sum

## 题意

从 word1/word2 交错取字符拼成 target：各自下标严格递增，且两边至少各取一次，求方案数模 1e9+7。

## 最优思路

记忆化搜索 (target 位置, 两串指针, 是否已用)，用 next 数组跳到下一个匹配字符。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```
