# LC 3948. Lexicographically Maximum MEX Array

> Hard · [LeetCode](https://leetcode.com/problems/lexicographically-maximum-mex-array/) · Tags: Array, Hash Table, Greedy, Queue

## 题意

反复取 nums 某个前缀的 MEX 写入结果并删掉该前缀，求字典序最大的结果数组。

## 最优思路

字典序最大要求尽早得到尽量大的 MEX：每次切到“能使 MEX 再增大所必需的最右位置”，直到再也构不出正 MEX，剩余全补 0。

```text
输入 → 关键建模 → 最优算法 → 答案
```
