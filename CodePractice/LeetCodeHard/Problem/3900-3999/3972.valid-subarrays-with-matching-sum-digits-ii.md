# LC 3972. Valid Subarrays With Matching Sum Digits II

> Hard · [LeetCode](https://leetcode.com/problems/valid-subarrays-with-matching-sum-digits-ii/) · Tags: Array, Hash Table, Sliding Window, Prefix Sum

## 题意

给你一个整数数组 nums 和一个整数数字 x 。 如果一个 子数组 nums[l..r] 的元素和同时满足以下两个条件，则认为该子数组是 有效子数组 ： 该和的首位数字等于 x 。 该和的末位数字等于 x 。 返回有效子数组的数量。 子数组 是数组中一个连续 、非空 的元素序列。 示例 1： 输入： nums = [1,100,1], x = 1 输出： 4 解释： 有效子数组为： nums[0..0] ： sum = 1 nums[0..1] ： sum = 1 + 100 = 101 nums[1..2] ： sum = 100 + 1 = …
