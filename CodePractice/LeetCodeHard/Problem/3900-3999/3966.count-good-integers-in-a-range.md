# LC 3966. Count Good Integers in a Range

> Hard · [LeetCode](https://leetcode.com/problems/count-good-integers-in-a-range/) · Tags: Math, Dynamic Programming

## 题意

统计 [l,r] 中相邻数位差绝对值均 ≤k 的整数个数（l,r 可达 1e15）。

## 最优思路

数位 DP：位置、上一位、是否贴上界、是否已开始。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(log r · 10) |
| 空间 | O(log r) |
