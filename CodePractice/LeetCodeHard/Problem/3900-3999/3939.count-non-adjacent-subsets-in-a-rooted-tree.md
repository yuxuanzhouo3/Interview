# LC 3939. Count Non Adjacent Subsets in a Rooted Tree

> Hard · [LeetCode](https://leetcode.com/problems/count-non-adjacent-subsets-in-a-rooted-tree/) · Tags: Array, Dynamic Programming, Tree, Depth-First Search

## 题意

有根树上选非空独立集（父子不同时选），节点值和能被 k 整除的方案数，模 1e9+7。

## 最优思路

树上背包：子树维护选/不选根时的模 k 方案。合并子树时对模做卷积；选根时子节点必须不选。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(n k^2) |
| 空间 | O(n k) |
