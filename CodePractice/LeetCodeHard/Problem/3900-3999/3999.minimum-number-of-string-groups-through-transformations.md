# LC 3999. Minimum Number of String Groups Through Transformations

> Hard · [LeetCode](https://leetcode.com/problems/minimum-number-of-string-groups-through-transformations/) · Tags: Hash Table, Two Pointers, String

## 题意

对每个字符串可独立循环右移偶数位/奇数位子序列。等价的字符串分到同一组，求最少组数。

## 最优思路

循环移位的标准形是最小旋转（Booth）。把偶/奇子串各自规范后拼成键，不同键个数即组数。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```
