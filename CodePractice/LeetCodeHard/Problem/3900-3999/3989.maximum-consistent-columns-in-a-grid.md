# LC 3989. Maximum Consistent Columns in a Grid

> Hard · [LeetCode](https://leetcode.com/problems/maximum-consistent-columns-in-a-grid/) · Tags: Array, Dynamic Programming, Matrix

## 题意

删除若干列（至少留一列）使任意相邻保留列在每一行的绝对差 ≤ limit，求最多保留列数。

## 最优思路

列序列 DP：dp[j]=以 j 结尾的最长合法列子序列，转移检查所有行差值。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```
