# LC 1168. Optimize Water Distribution in a Village

> Hard · [LeetCode](https://leetcode.com/problems/optimize-water-distribution-in-a-village/) · Premium · Tags: Union-Find, MST

## 题意

每个房子可打井或铺水管连通，求供水最小成本。

## 最优思路

建虚拟节点 0 连到各村（边权=打井），再加水管边，Kruskal 求 MST。

## 图解

```text
Input → 虚拟水源点 0 + Kruskal MST → Answer
```
