# LC 1121. Divide Array Into Increasing Sequences

> Hard · [LeetCode](https://leetcode.com/problems/divide-array-into-increasing-sequences/) · Premium · Tags: Array, Counting

## 题意

非降数组能否分成若干严格递增子序列且每段长度 ≥ K。

## 最优思路

同值不能共段 ⇒ 至少需要 max_freq 段；故 max_freq * K ≤ n。

## 图解

```text
Input → 最大频次 ≤ ⌊n/K⌋ 的序列数约束 → Answer
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(n) |
| 空间 | O(n) |
