# LC 1153. String Transforms Into Another String

> Hard · [LeetCode](https://leetcode.com/problems/string-transforms-into-another-string/) · Premium · Tags: Hash Table, String, Graph

## 题意

判断能否通过一系列「把某字符全局改成另一字符」把 str1 变成 str2。

## 最优思路

建立一对一映射；若出现冲突则否。有环时需要临时字符，故 str2 字母种类须 < 26。

## 图解

```text
Input → 映射图：无环或存在未使用字符可破环 → Answer
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(n) |
| 空间 | O(1) |
