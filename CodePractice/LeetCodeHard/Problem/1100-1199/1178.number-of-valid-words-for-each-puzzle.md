# LC 1178. Number of Valid Words for Each Puzzle

> Hard · [LeetCode](https://leetcode.com/problems/number-of-valid-words-for-each-puzzle/) · Tags: Array, Hash Table, String, Bit Manipulation, Trie

## 题意

对每个 7 字母谜题，统计有多少单词：包含谜题首字母，且单词字母都出现在谜题中。

## 最优思路

把单词压成 ≤7 位 bitmask 并计数；对每个谜题枚举其 mask 的所有子集，累加包含首字母的子集出现次数。

## 图解

```text
word → bitmask → Counter
puzzle mask → 枚举 sub ⊆ mask 且含 first bit
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(\sum|w| + P\cdot 2^{7})\) |
| 空间 | \(O(W)\) |
