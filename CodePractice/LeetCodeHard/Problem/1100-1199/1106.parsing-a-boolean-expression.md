# LC 1106. Parsing A Boolean Expression

> Hard · [LeetCode](https://leetcode.com/problems/parsing-a-boolean-expression/) · Tags: String, Stack, Recursion

## 题意

解析布尔表达式：`t`/`f`、`!(...)`、`&(...)`、`|(...)`，返回真假。

## 最优思路

递归下降：遇运算符解析括号内逗号分隔子表达式，再按 `!`/`&`/`|` 求值。

## 图解

```mermaid
flowchart TD
  A[读运算符] --> B[解析括号内]
  B --> C[!, &, |]
  C --> D[布尔值]

```
