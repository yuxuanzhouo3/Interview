# LC 1187. Make Array Strictly Increasing

> Hard · [LeetCode](https://leetcode.com/problems/make-array-strictly-increasing/) · Tags: Array, Binary Search, DP, Sorting

## 题意

可用 `arr2` 中的值替换 `arr1` 元素任意次，使 `arr1` 严格递增；求最少替换次数，不可能则 `-1`。

## 最优思路

状态：处理完某位置后，以「末尾值 → 最少操作」映射。对每个末尾：

1. 若当前 `a` 大于末尾，可保留；
2. 在 `arr2` 中二分找 `> last` 的最小元素替换。

滚动 map，最终取最小 ops。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\cdot m\log m)\) 最坏状态数受 \(|arr2|\) 约束 |
| 空间 | \(O(m)\) |
