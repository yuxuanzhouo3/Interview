# LC 1163. Last Substring in Lexicographical Order

> Hard · [LeetCode](https://leetcode.com/problems/last-substring-in-lexicographical-order/) · Tags: Two Pointers, String, Lyndon Factorization

## 题意

给定字符串 `s`，返回其所有非空子串中**字典序最大**的那一个（若有多个相同，任取其一；题目保证唯一最长起点）。

## 最优思路

双指针 Duval 风格：`i` 为当前最优起点，`j` 为候选起点，`k` 为共同前缀长度。

- `s[i+k] < s[j+k]` → `i` 败，`i += k+1`
- 否则 `j` 败，`j += k+1`
- `i==j` 时 `j++`，重置 `k`

线性扫描后答案为 `s[i:]`。

## 图解

```text
i ----→ 比较共同前缀 k
j ----→
谁在分歧处更小，谁的起点整体后移
```
