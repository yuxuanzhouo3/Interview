# LC 1183. Maximum Number of Ones

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-ones/) · Premium · Tags: Math, Greedy

## 题意

在矩阵中放最多 maxOnes 个 1，使任意 sideLength×sideLength 子矩阵中 1 的个数 ≤ maxOnes，求全局最多 1。

## 最优思路

等价于在周期模板内选 maxOnes 个位置；按各 residual 位置覆盖格子数贪心取最大。

## 图解

```text
Input → 按 sideLength 瓦片位置出现频次取前 maxOnes → Answer
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(s² log s) |
| 空间 | O(s²) |
