# LC 1199. Minimum Time to Build Blocks

> Hard · [LeetCode](https://leetcode.com/problems/minimum-time-to-build-blocks/) · Premium · Tags: Greedy, Heap

## 题意

每块木头建造时间不同；工人可分裂（耗时 split）。求建完所有块的最短时间。

## 最优思路

逆向 Huffman：反复取出最小两值，把较大者+split 压回堆。

## 图解

```text
Input → 逆向 Huffman：优先合并最大两块并加 split → Answer
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(n log n) |
| 空间 | O(n) |
