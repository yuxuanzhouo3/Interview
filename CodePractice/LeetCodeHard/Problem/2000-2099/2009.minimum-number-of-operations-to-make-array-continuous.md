# LC 2009. Minimum Number of Operations to Make Array Continuous

> Hard · [LeetCode](https://leetcode.com/problems/minimum-number-of-operations-to-make-array-continuous/) · Tags: Array, Binary Search, Sliding Window

## 题意

每次把一个元素改成任意值。使数组「连续」：`max-min+1 == n` 且元素互异。求最少修改次数。

## 最优思路

去重排序后，滑动/二分找落在窗口 `[x, x+n-1]` 内的唯一值个数 `k`，修改次数 `n-k`，取最小。

## 图解

```text
唯一值: … x …… y …
窗口长度 n：尽量多留下，其余改掉
```
