# LC 2003. Smallest Missing Genetic Value in Each Subtree

> Hard · [LeetCode](https://leetcode.com/problems/smallest-missing-genetic-value-in-each-subtree/) · Tags: Array, Dynamic Programming, Tree, Depth-First Search, Union-Find

## 题意

每个节点子树基因的 mex（最小缺失正整数）；`nums` 互不相同。

## 最优思路

不含 `1` 的子树 mex 恒为 1。从值为 1 的节点沿父链向上，累加旁支子树基因集合，维护递增 mex。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
