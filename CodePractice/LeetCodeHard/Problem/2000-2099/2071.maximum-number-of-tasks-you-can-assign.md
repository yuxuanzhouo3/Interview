# LC 2071. Maximum Number of Tasks You Can Assign

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-tasks-you-can-assign/) · Tags: Array, Binary Search, Greedy, Queue, Sorting

## 题意

任务需求 `tasks[i]`，工人力量 `workers[j]`。最多 `pills` 颗药，服药后力量 `+strength`。每人最多一任务。求最多可完成任务数。

## 最优思路

二分任务数 `k`：取最易 `k` 个任务与最强 `k` 个工人。工人从弱到强：把当前工人服药能做的任务入双端队列；能直接做则做最易，否则服药做最难。
