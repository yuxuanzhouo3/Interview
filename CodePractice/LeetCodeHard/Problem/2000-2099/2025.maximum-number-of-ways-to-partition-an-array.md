# LC 2025. Maximum Number of Ways to Partition an Array

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-ways-to-partition-an-array/) · Tags: Array, Hash Table, Counting, Enumeration, Prefix Sum

## 题意

至多把一个元素改成 `k`，求使数组在某枢轴左右和相等的划分数最大值。

## 最优思路

前缀和；改 `nums[j]` 产生 `delta`。按枢轴相对 `j` 左右分别用哈希统计满足方程的前缀个数；并与不修改比较。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
