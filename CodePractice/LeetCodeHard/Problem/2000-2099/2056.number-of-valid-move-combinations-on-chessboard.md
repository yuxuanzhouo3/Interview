# LC 2056. Number of Valid Move Combinations On Chessboard

> Hard · [LeetCode](https://leetcode.com/problems/number-of-valid-move-combinations-on-chessboard/) · Tags: Backtracking, Simulation

## 题意

棋盘上若干车/象/后各选一次移动（可停），路径任意时刻不撞，求组合数。

## 最优思路

每子枚举目标射线路径（含原地），笛卡尔积后按时间步查重。

## 图解

```text
t=0..T: positions must be unique
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | 枚举可接受 |
| 空间 | O(组合) |
