# LC 1601. Maximum Number of Achievable Transfer Requests

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-achievable-transfer-requests/) · Tags: Array, Backtracking, Enumeration, Bit Manipulation

## 题意

若干从楼 `a` 到 `b` 的调职请求；净流入均为 0 才可同时批准。求最多批准数。

## 最优思路

请求 ≤16，枚举子集，检查各楼净变化是否全 0。

## 复杂度

| 项 | 值 |

| 时间 | \(O(2^m\cdot n)\) |
| 空间 | \(O(n)\) |
