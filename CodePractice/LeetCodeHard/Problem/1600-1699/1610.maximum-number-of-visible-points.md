# LC 1610. Maximum Number of Visible Points

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-visible-points/) · Tags: Array, Math, Geometry, Sliding Window, Sorting

## 题意

视野视角为 `angle` 度、原点在 `location`，求一转角下最多能看到多少点（同位置点始终可见）。

## 最优思路

用 `atan2` 得相对角度，排序后复制一份 `+2π` 处理环；滑动窗口找跨度 ≤ `angle` 的最多点数，再加同位置点数。

## 图解

```mermaid
flowchart LR
  P[点] --> A[atan2 角度]
  A --> S[排序 + 复制 2π]
  S --> W[滑动窗口 max]
  W --> R["+ 同位置"]
```
