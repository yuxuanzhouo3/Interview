# LC 1622. Fancy Sequence

> Hard · [LeetCode](https://leetcode.com/problems/fancy-sequence/) · Tags: Math, Design

## 题意

序列支持末尾追加、全体加、全体乘、按下标查询（模 \(10^9+7\)）。

## 最优思路

维护全局仿射 \(x \mapsto mul\cdot x+add\)；追加时存“逆变换”后的值，查询再套当前变换。

## 图解

```text
stored = (val - add) * inv(mul)
query  = stored * mul + add
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | 每次 \(O(1)\) / \(O(\log MOD)\) 求逆 |
| 空间 | \(O(n)\) |
