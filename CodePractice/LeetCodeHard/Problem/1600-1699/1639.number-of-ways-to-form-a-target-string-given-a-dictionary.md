# LC 1639. Number of Ways to Form a Target String Given a Dictionary

> Hard · [LeetCode](https://leetcode.com/problems/number-of-ways-to-form-a-target-string-given-a-dictionary/) · Tags: Array, String, Dynamic Programming

## 题意

字典 `words`（等长），按列选字母拼出 `target`（每列至多用一次且列递增），求方案数 mod \(10^9+7\)。

## 最优思路

预处理 `count[j][c]`：第 `j` 列字母 `c` 出现次数。`dp[i][j]` = 用前 `j` 列拼出 `target[:i]` 的方案；转移：跳过该列，或用该列匹配 `target[i-1]`。

## 图解

```mermaid
flowchart LR
  C[count 列字符] --> D["dp[i][j]"]
  D --> S[跳过 / 取该列]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(m\cdot(|target|+|\Sigma|)\cdot|words|)\) 预处理后 \(O(|target|\cdot m)\) |
| 空间 | \(O(|target|\cdot m)\) |
