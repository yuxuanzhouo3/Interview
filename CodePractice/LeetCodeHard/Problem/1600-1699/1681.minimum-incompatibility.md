# LC 1681. Minimum Incompatibility

> Hard · [LeetCode](https://leetcode.com/problems/minimum-incompatibility/) · Tags: DP, Bitmask

## 题意

把 `n` 个数均分到 `k` 组，组内互异；不兼容度=组内 max-min 之和，求最小，不可能则 -1。

## 最优思路

预处理合法组掩码代价，再子集 DP 拼满全集。

## 图解

```text
valid group masks → dp[mask] min cost
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(3^n)\) |
| 空间 | \(O(2^n)\) |
