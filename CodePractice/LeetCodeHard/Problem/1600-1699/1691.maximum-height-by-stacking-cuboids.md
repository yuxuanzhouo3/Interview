# LC 1691. Maximum Height by Stacking Cuboids

> Hard · [LeetCode](https://leetcode.com/problems/maximum-height-by-stacking-cuboids/) · Tags: Array, Dynamic Programming, Sorting

## 题意

每个长方体可任意旋转边长。`i` 可叠在 `j` 上当且仅当三维边长都 ≤。求最大堆叠高度。

## 最优思路

每个 cuboid 三边排序（最优朝向）；全体再排序。`dp[i]` = 以 `i` 为顶的最大高度，若 `w,l,h` 均可 ≤ 则从 `j` 转移（LIS 式）。
