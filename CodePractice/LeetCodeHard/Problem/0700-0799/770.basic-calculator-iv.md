# LC 770. Basic Calculator IV

> Hard · [LeetCode](https://leetcode.com/problems/basic-calculator-iv/) · Tags: Hash Table, Math, String, Stack

## 题意

求含变量的表达式值：已知变量代入后，把结果整理成多项式项列表（按次数降序、字典序）。

## 最优思路

递归下降解析 `expr/term/factor`；每项用 `Counter[tuple(vars)]→coef` 表示，乘法则合并变量元组并排序。

## 图解

```text
(e+8)*(e-8) → e*e + … → ["1*e*e","-64"]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\cdot T)\)（\(T\) 为项数） |
| 空间 | \(O(T)\) |
