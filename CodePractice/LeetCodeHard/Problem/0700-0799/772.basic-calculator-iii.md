# LC 772. Basic Calculator III

> Hard · [LeetCode](https://leetcode.com/problems/basic-calculator-iii/) · Tags: Math, String, Stack, Recursion

## 题意

计算含 `+ - * /` 与括号的整数表达式（除法向零截断）。

## 最优思路

递归下降：遇 `(` 递归；栈处理加减，乘除立即与栈顶合并。

## 图解

```text
2*(5+5*2)/3+(6/2+8)
     └ recurse ┘
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
