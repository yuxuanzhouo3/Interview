# LC 716. Max Stack

> Hard · [LeetCode](https://leetcode.com/problems/max-stack/) · Tags: Stack, Design, Heap

## 题意

设计支持 `push/pop/top/peekMax/popMax` 的栈；`popMax` 弹出最大元素（多个取靠近栈顶者）。

## 最优思路

普通栈 + 最大堆存 `(val,id)`，删除用懒标记；读写前清理栈顶/堆顶已删元素。

## 图解

```text
stack: … (v,id)
heap:  (-v,-id)
removed set for lazy GC
```
