# LC 711. Number of Distinct Islands II

> Hard · [LeetCode](https://leetcode.com/problems/number-of-distinct-islands-ii/) · Premium · Tags: DFS, Hash, Geometry

## 题意

统计不同岛屿形状数，旋转与镜像视为相同。

## 最优思路

DFS 收集坐标；对 8 种正交变换规范化后取字典序最小作为签名。

## 图解

```text
Input → DFS 取点集 + 8 种变换规范化 → Answer
```

| 时间 | O(mn log mn) |
| 空间 | O(mn) |
