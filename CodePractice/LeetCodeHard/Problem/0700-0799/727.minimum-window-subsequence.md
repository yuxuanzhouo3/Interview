# LC 727. Minimum Window Subsequence

> Hard · [LeetCode](https://leetcode.com/problems/minimum-window-subsequence/) · Tags: String, DP, Sliding Window

## 题意

在 `s1` 中找最短子串，使 `s2` 为其子序列；同长取最左。

## 最优思路

正向扫找到覆盖 `s2` 的右端，再反向缩到最左起点；从下一位置重复，维护最短窗。

## 图解

```text
s1: a b c d e b d d e
s2:     b     d   e
forward → end, backward → start
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(|s1|\cdot|s2|)\) |
| 空间 | \(O(1)\) |
