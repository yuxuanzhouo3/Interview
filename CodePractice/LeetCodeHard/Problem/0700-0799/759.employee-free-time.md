# LC 759. Employee Free Time

> Hard · [LeetCode](https://leetcode.com/problems/employee-free-time/) · Premium · Tags: Array, Sorting, Heap

## 题意

所有员工忙碌区间已知，求大家共同空闲的区间列表。

## 最优思路

摊平所有区间排序合并，相邻合并块之间的空隙即共同空闲。

## 图解

```text
Input → 合并所有忙碌区间后取空隙 → Answer
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(n log n) |
| 空间 | O(n) |
