# LC 719. Find K-th Smallest Pair Distance

> Hard · [LeetCode](https://leetcode.com/problems/find-k-th-smallest-pair-distance/)

## 题意

第 k 小的数对距离 `|ai-aj|`。

## 最优思路

排序后二分距离；双指针统计 ≤mid 的对数。

## 图解

```mermaid
flowchart LR
  Sort --> BinSearch
  BinSearch --> TwoPointersCount
```

| 项 | 值 |
|----|----|
