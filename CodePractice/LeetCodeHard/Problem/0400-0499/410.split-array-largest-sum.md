# LC 410. Split Array Largest Sum

> Hard · [LeetCode](https://leetcode.com/problems/split-array-largest-sum/)

## 题意

切成 k 段，最小化「段和最大值」。

## 最优思路

二分答案；贪心检查能否在上限 mid 下切成 ≤k 段。

## 图解

```text
binary search largest-sum ∈ [max(nums), sum]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log S)\) |
| 空间 | \(O(1)\) |
