# LC 420. Strong Password Checker

> Hard · [LeetCode](https://leetcode.com/problems/strong-password-checker/)

## 题意

最少修改次数使密码满足强弱规则（长度/类别/无连续3相同）。

## 最优思路

按长度分 `<6 / ≤20 / >20`；长串优先用删除化解 3 连，再替换补类型。

## 图解

```text
len cases + replace for aaa runs
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(1)\) |
