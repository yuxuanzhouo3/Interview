# LC 2426. Number of Pairs Satisfying Inequality

> Hard · [LeetCode](https://leetcode.com/problems/number-of-pairs-satisfying-inequality/) · Tags: Array, Binary Search, Divide and Conquer, Binary Indexed Tree, Segment Tree, Merge Sort, Ordered Set

## 题意

统计 `i < j` 且 `nums1[i]-nums1[j] ≤ nums2[i]-nums2[j]+diff` 的对数。

## 最优思路

令 `arr[i]=nums1[i]-nums2[i]`，即 `arr[i] ≤ arr[j]+diff`。归并排序统计。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log n)\) |
| 空间 | \(O(n)\) |
