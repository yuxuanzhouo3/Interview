# LC 2454. Next Greater Element IV

> Hard · [LeetCode](https://leetcode.com/problems/next-greater-element-iv/) · Tags: Monotonic Stack

## 题意

对每个下标求**第二个**更大元素；不存在则为 -1。

## 最优思路

双单调栈：`s1` 尚未遇到第一个更大，`s2` 已遇一个更大、等第二个；扫到更大值时更新 `s2` 并迁移 `s1→s2`。

## 图解

```text
s1: waiting 1st greater
s2: waiting 2nd greater → write answer
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
