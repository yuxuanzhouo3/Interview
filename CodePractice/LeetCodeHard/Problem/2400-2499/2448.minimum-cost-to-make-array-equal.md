# LC 2448. Minimum Cost to Make Array Equal

> Hard · [LeetCode](https://leetcode.com/problems/minimum-cost-to-make-array-equal/) · Tags: Greedy, Sorting, Weighted Median

## 题意

把所有数改成同一值；把 `nums[i]` 改 1 的代价为 `cost[i]`；求最小总代价。

## 最优思路

最优目标为**加权中位数**；排序累加 cost 至 ≥ 总和一半。

## 图解

```text
sort by value; prefix cost ≥ total/2 → median
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log n)\) |
| 空间 | \(O(n)\) |
