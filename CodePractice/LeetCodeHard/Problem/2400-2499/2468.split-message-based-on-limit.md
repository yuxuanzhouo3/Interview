# LC 2468. Split Message Based on Limit

> Hard · [LeetCode](https://leetcode.com/problems/split-message-based-on-limit/) · Tags: String, Enumeration

## 题意

把消息拆成带 `<i/k>` 后缀的段，每段长 ≤ limit，求字典序最小的拆分（即最小 k）。

## 最优思路

枚举总段数 k，用位数公式判断有效载荷是否够装下整条消息。

## 图解

```text
payload = limit*k - Σ|str(i)| - |str(k)|*k - 3k
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
