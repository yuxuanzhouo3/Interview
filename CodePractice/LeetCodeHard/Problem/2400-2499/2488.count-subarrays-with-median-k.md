# LC 2488. Count Subarrays With Median K

> Hard · [LeetCode](https://leetcode.com/problems/count-subarrays-with-median-k/) · Tags: Array, Prefix Sum, Hash Table

## 题意

统计中位数恰好为 `k` 的子数组个数（`k` 在数组中唯一）。

## 最优思路

以 `k` 位置为中心；左边 balance（>k 为 +1）频率表；向右扩展时查 `bal` 与 `bal-1`。

## 图解

```text
left freq[balance] × right balance ∈ {0,1} relative
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
