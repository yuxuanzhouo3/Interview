# LC 2416. Sum of Prefix Scores of Strings

> Hard · [LeetCode](https://leetcode.com/problems/sum-of-prefix-scores-of-strings/) · Tags: Trie, String

## 题意

对每个单词，其所有前缀在整个数组中出现次数之和。

## 最优思路

建 Trie，插入时路径节点 `cnt++`；查询时沿路径累加 `cnt`。

## 图解

```text
Trie path "ab" → nodes count how many words share this prefix
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(\sum |w|)\) |
| 空间 | \(O(\sum |w|)\) |
