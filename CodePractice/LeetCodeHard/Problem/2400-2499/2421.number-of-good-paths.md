# LC 2421. Number of Good Paths

> Hard · [LeetCode](https://leetcode.com/problems/number-of-good-paths/) · Tags: Tree, Union-Find

## 题意

树上两端点值相等且路径上最大值不超过该值的路径条数（含单点）。

## 最优思路

按节点值升序并查集连通「≤ 当前值」的邻居；同值节点在同一连通块内两两构成好路径。

## 图解

```text
process values small→large; UF merges; C(c,2) per component
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log n)\) |
| 空间 | \(O(n)\) |
