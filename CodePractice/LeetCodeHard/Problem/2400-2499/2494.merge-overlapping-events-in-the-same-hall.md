# LC 2494. Merge Overlapping Events in the Same Hall

> Hard · [LeetCode](https://leetcode.com/problems/merge-overlapping-events-in-the-same-hall/) · Tags: Database

## 题意

按 hall 合并重叠/相邻的活动区间。

## 最优思路

窗口取前缀最大 end，标记新段后分组聚合。

## 图解

```text
events -> merge overlapping per hall
```
