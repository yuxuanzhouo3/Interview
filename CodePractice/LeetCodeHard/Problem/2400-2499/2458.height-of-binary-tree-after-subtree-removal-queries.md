# LC 2458. Height of Binary Tree After Subtree Removal Queries

> Hard · [LeetCode](https://leetcode.com/problems/height-of-binary-tree-after-subtree-removal-queries/) · Tags: Tree, DFS, Binary Tree

## 题意

对每个查询节点，删除以其为根的子树后，原树高度是多少。

## 最优思路

先算各子树高；再 DFS 时把「不走当前子树时的最大高度」传给子节点。

## 图解

```text
rest = max height if current subtree removed
pass to child: max(rest, depth+1+sibling_height)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n+q)\) |
| 空间 | \(O(n)\) |
