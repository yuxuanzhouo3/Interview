# LC 2478. Number of Beautiful Partitions

> Hard · [LeetCode](https://leetcode.com/problems/number-of-beautiful-partitions/) · Tags: String, Dynamic Programming, Prefix Sum

## 题意

把数字串分成 `k` 段，每段以质数数字开头、非质数结尾，且长度 ≥ `minLength`。

## 最优思路

DP：从位置 `i` 分 `p` 段；枚举第一段合法结尾。约束：`n≤1000` 时 \(O(n^2 k)\) 可过。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2 k)\) |
| 空间 | \(O(nk)\) |
