# LC 2449. Minimum Number of Operations to Make Arrays Similar

> Hard · [LeetCode](https://leetcode.com/problems/minimum-number-of-operations-to-make-arrays-similar/) · Tags: Array, Greedy, Sorting

## 题意

一次操作：某元素 +2、另一元素 −2；使 `nums` 可重排等于 `target` 的最少操作数。

## 最优思路

奇偶各自排序对齐；总绝对差之和除以 4（每次操作减少总差 4）。

## 图解

```text
odd/even separately sorted: Σ|a-b| / 4
```

## 复杂度

| 项 | 值 |

| 时间 | \(O(n\log n)\) |
| 空间 | \(O(n)\) |
