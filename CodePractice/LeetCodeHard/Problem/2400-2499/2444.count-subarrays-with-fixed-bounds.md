# LC 2444. Count Subarrays With Fixed Bounds

> Hard · [LeetCode](https://leetcode.com/problems/count-subarrays-with-fixed-bounds/) · Tags: Array, Sliding Window

## 题意

统计子数组个数：最小值恰为 `minK` 且最大值恰为 `maxK`。

## 最优思路

扫描维护最近 `minK`/`maxK`/越界位置；以 `i` 为右端时，左端可在 `(ibad, min(imin,imax)]`。

## 图解

```text
... bad | ... minK ... maxK ... i
         ↑ left choices
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(1)\) |
