# LC 2472. Maximum Number of Non-Overlapping Palindrome Substrings

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-non-overlapping-palindrome-substrings/) · Tags: String, Greedy, DP

## 题意

选尽量多互不重叠的回文子串，每个长度 ≥ `k`。

## 最优思路

从左贪心：每次取能找到的最短回文（长度 `k` 或 `k+1` 优先），再跳到其后。

## 图解

```text
…[pal≥k]…[pal≥k]…  →  maximize count
```

## 复杂度

| 项 | 值 |

| 时间 | \(O(n^2)\) |
| 空间 | \(O(1)\) |
