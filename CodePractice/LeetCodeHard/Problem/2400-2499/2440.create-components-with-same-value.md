# LC 2440. Create Components With Same Value

> Hard · [LeetCode](https://leetcode.com/problems/create-components-with-same-value/) · Tags: Array, Math, Tree, Depth-First Search, Enumeration

## 题意

删边使各连通块结点值和相等，求最多删边数。

## 最优思路

总和 \(S\)，块数为 \(k\) 则每块和 \(S/k\)。从大到小枚举可整除的 \(k\)，DFS 校验能否切出。

## 图解

```text
目标和 t=S/k，子树和==t 则切掉（返回0）
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n \cdot d(S))\) |
| 空间 | \(O(n)\) |
