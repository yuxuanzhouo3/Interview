# LC 2493. Divide Nodes Into the Maximum Number of Groups

> Hard · [LeetCode](https://leetcode.com/problems/divide-nodes-into-the-maximum-number-of-groups/) · Tags: BFS, Graph, Bipartite

## 题意

给连通分量染色分组：相邻节点组号差 1；求最大组数之和，非二分图返回 -1。

## 最优思路

各连通块先判二分；再对块内每点 BFS 取最大层数，块贡献该最大值。

## 图解

```text
component groups = max BFS depth over starts
```
