# LC 2430. Maximum Deletions on a String

> Hard · [LeetCode](https://leetcode.com/problems/maximum-deletions-on-a-string/) · Tags: String, Dynamic Programming, Rolling Hash, String Matching, Hash Function

## 题意

每次删除当前串的某个「与其后等长前缀相同」的前缀，求最多删除次数。

## 最优思路

预计算 LCP；`dp[i]` 从 `s[i:]` 出发最多删几次，枚举可删长度转移。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2)\) |
| 空间 | \(O(n^2)\) |
