# LC 2642. Design Graph With Shortest Path Calculator

> Hard · [LeetCode](https://leetcode.com/problems/design-graph-with-shortest-path-calculator/) · Tags: Graph, Design, Dijkstra

## 题意

有向带权图：支持加边与求两点最短路（不可达 -1）。

## 最优思路

邻接表存图；每次查询 Dijkstra。

## 图解

```text
addEdge → append adj
shortestPath → Dijkstra
```

## 复杂度

| 项 | 值 |
|----|----|
| 查询 | \(O((n+e)\log n)\) |
| 加边 | \(O(1)\) |
