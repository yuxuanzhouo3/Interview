# LC 2659. Make Array Empty

> Hard · [LeetCode](https://leetcode.com/problems/make-array-empty/) · Tags: Array, Binary Search, Greedy, Binary Indexed Tree, Segment Tree, Sorting, Ordered Set

## 题意

循环数组：每次可删当前最小，或把当前移到末尾；求清空数组最少操作数。

## 最优思路

按值从小到大删。若下一个最小值在当前位置左侧，需额外绕一整圈剩余元素。公式：`n + Σ (n-i)`（每当位置回绕）。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log n)\) |
| 空间 | \(O(n)\) |
