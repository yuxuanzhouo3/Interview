# LC 2630. Memoize II

> Hard · [LeetCode](https://leetcode.com/problems/memoize-ii/) · Tags: —

## 题意

（原题为 JS）实现按**参数对象身份**记忆化的高阶函数（相同引用命中缓存，不同对象即使深等也不命中）。

## 最优思路

用 `id` 映射到递增下标，参数列表拼成缓存键；调用时查表。

## 图解

```text
args → map each to identity index → join key → cache
```

## 复杂度

| 项 | 值 |
|----|----|
| 查/写 | 摊还 \(O(1)\)（相对参数个数） |
| 空间 | \(O(\text{distinct calls})\) |
