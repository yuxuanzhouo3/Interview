# LC 2663. Lexicographically Smallest Beautiful String

> Hard · [LeetCode](https://leetcode.com/problems/lexicographically-smallest-beautiful-string/) · Tags: String, Greedy

## 题意

在字母表大小 `k` 下，找字典序严格大于 `s` 的最短同长「美丽串」（无长为 2 的回文子串）。

## 最优思路

从右往左增大某一位，再贪心把右侧填最小合法字母（避开与前 1、2 位相同）。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(nk)\) |
| 空间 | \(O(n)\) |
