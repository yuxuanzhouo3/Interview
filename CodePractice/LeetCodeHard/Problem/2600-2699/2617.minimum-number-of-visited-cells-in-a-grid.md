# LC 2617. Minimum Number of Visited Cells in a Grid

> Hard · [LeetCode](https://leetcode.com/problems/minimum-number-of-visited-cells-in-a-grid/) · Tags: BFS, Union-Find, Matrix

## 题意

从 `(i,j)` 可向右跳到 `[j+1, j+grid[i][j]]` 或向下类似；求到右下最少访问格数。

## 最优思路

BFS；用并查集跳过行/列上已访问位置，避免重复扩展，总复杂度近线性。

## 图解

```text
from (i,j) → row right / col down within jump range
UF skips visited indices
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(mn\alpha)\) |
| 空间 | \(O(mn)\) |
