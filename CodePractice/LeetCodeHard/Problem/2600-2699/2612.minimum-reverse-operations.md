# LC 2612. Minimum Reverse Operations

> Hard · [LeetCode](https://leetcode.com/problems/minimum-reverse-operations/) · Tags: Array, Hash Table, Breadth-First Search, Union-Find, Ordered Set

## 题意

长 `k` 窗口翻转，求从 `p` 到各位置最少翻转次数（banned 不可达）。

## 最优思路

一次翻转后位置奇偶与区间有公式范围；按奇偶分 `SortedSet` BFS，区间内未访问点全部扩展。

## 图解

```text
位置 i → [max(i-k+1, k-i-1), min(i+k-1, 2n-k-i-1)]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log n)\) |
| 空间 | \(O(n)\) |
