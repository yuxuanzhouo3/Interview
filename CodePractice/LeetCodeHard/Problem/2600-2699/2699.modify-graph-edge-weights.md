# LC 2699. Modify Graph Edge Weights

> Hard · [LeetCode](https://leetcode.com/problems/modify-graph-edge-weights/) · Tags: Graph, Shortest Path

## 题意

将权为 `-1` 的边改为正整数，使 `source→destination` 最短路恰为 `target`。

## 最优思路

1. 忽略 `-1`：若最短路已 `< target` 无解；`= target` 则其余设为大值。  
2. 否则把 `-1` 当 1，从终点算距离；再从起点 Dijkstra，遇 `-1` 赋 `max(1, target−d−fromDest[v])`。

## 图解

```text
fixed < target → []
fixed = target → -1→INF
else assign on frontier to hit target
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O((n+e)\log n)\) 量级（数次 Dijkstra） |
| 空间 | \(O(n+e)\) |
