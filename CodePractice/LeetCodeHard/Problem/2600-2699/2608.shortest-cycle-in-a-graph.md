# LC 2608. Shortest Cycle in a Graph

> Hard · [LeetCode](https://leetcode.com/problems/shortest-cycle-in-a-graph/) · Tags: BFS, Graph

## 题意

无向图最短环长度；无环返回 -1。

## 最优思路

从每个点 BFS；遇到已访问且非父节点的边，用 `dist[u]+dist[v]+1` 更新环长。

## 图解

```text
BFS tree + back edge → cycle length
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n(n+m))\) |
| 空间 | \(O(n+m)\) |
