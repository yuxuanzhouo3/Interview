# LC 1220. Count Vowels Permutation

> Hard · [LeetCode](https://leetcode.com/problems/count-vowels-permutation/) · Tags: Dynamic Programming

## 题意

长度为 `n` 的元音串，按转移规则计数。

## 最优思路

五状态 DP：按规则 `a←e`，`e←a/i`，`i←a/e/o/u`，`o←i/u`，`u←a` 迭代。

## 图解

```text
a→e→i→o→u  with given adjacency
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(1)\) |
