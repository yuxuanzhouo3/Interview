# LC 1289. Minimum Falling Path Sum II

> Hard · [LeetCode](https://leetcode.com/problems/minimum-falling-path-sum-ii/) · Tags: Array, Dynamic Programming, Matrix

## 题意

从第一行落到最后一行，相邻行不能选同一列，求路径和最小。

## 最优思路

每行维护上一行最小、次小值及下标；本行每列加「非同列的最小值」。

## 图解

```text
row r-1: … m1@i1 … m2 …
row r:   col j ← m2 if j==i1 else m1
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2)\) |
| 空间 | \(O(n)\) |
