# LC 1269. Number of Ways to Stay in the Same Place After Some Steps

> Hard · [LeetCode](https://leetcode.com/problems/number-of-ways-to-stay-in-the-same-place-after-some-steps/) · Tags: Dynamic Programming

## 题意

长度为 `arrLen` 的数组上走 `steps` 步（左/右/停），求回到 0 的方案数（mod \(10^9+7\)）。

## 最优思路

`dp[i]` = 当前在位置 `i` 的方案。有效位置不超过 `steps/2+1`。每步转移来自 `i-1,i,i+1`。

## 图解

```text
pos: 0—1—2—…  stay / left / right
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(\textit{steps}\cdot\min(\textit{arrLen},\textit{steps}))\) |
| 空间 | \(O(\min(\textit{arrLen},\textit{steps}))\) |
