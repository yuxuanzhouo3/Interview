# LC 1293. Shortest Path in a Grid with Obstacles Elimination

> Hard · [LeetCode](https://leetcode.com/problems/shortest-path-in-a-grid-with-obstacles-elimination/) · Tags: Array, BFS, Matrix

## 题意

网格从左上到右下，可消除至多 `k` 个障碍，求最短路径长度。

## 最优思路

BFS 状态 `(r,c,剩余消除次数)`；同一格仅当剩余次数更大时再入队。

## 图解

```text
(0,0,k) → … → (m-1,n-1,*)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(mnk)\) |
| 空间 | \(O(mn)\) |
