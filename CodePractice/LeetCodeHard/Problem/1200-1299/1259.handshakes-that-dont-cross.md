# LC 1259. Handshakes That Don't Cross

> Hard · [LeetCode](https://leetcode.com/problems/handshakes-that-dont-cross/) · Premium · Tags: Math, DP, Catalan

## 题意

偶数人围圆握手且不相交的方案数。

## 最优思路

经典卡特兰：dp[i]=Σ dp[j]*dp[i-1-j]。

## 图解

```text
Input → 卡特兰数 DP → Answer
```
