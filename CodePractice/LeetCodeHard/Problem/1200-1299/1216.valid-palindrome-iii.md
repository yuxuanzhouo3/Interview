# LC 1216. Valid Palindrome III

> Hard · [LeetCode](https://leetcode.com/problems/valid-palindrome-iii/) · Premium · Tags: String, DP

## 题意

判断能否删除至多 k 个字符使 s 成为回文。

## 最优思路

最长回文子序列 LPS；删除数 = n - LPS，判断 ≤ k。

## 图解

```text
Input → n - LPS ≤ k → Answer
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(n²) |
| 空间 | O(n²) |
