# LC 1203. Sort Items by Groups Respecting Dependencies

> Hard · [LeetCode](https://leetcode.com/problems/sort-items-by-groups-respecting-dependencies/) · Tags: Graph, Topological Sort

## 题意

`n` 个项目分属若干组，有先后依赖；同组须连续出现。求满足依赖的排列，无解返回 `[]`。

## 最优思路

无组项目各成独立组；建**组间**与**项目间**两张图分别拓扑。按组序拼接组内按项目拓扑序排列的结果。

## 图解

```text
items → topo
groups → topo
output = concat(sorted items of each group in group-order)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n+e)\) |
| 空间 | \(O(n+e)\) |
