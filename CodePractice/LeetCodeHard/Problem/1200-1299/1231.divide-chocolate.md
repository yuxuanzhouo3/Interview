# LC 1231. Divide Chocolate

> Hard · [LeetCode](https://leetcode.com/problems/divide-chocolate/) · Premium · Tags: Binary Search

## 题意

把巧克力切成 K+1 块，最大化你那块的最小甜度和。

## 最优思路

二分答案 x，贪心累计能否切出 ≥ K+1 段且每段和 ≥ x。

## 图解

```text
Input → 二分最小甜度 + 贪心切段 → Answer
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(n log S) |
| 空间 | O(1) |
