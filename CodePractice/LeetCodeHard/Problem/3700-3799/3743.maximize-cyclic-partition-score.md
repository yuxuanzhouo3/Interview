# LC 3743. Maximize Cyclic Partition Score

> Hard · [LeetCode](https://leetcode.com/problems/maximize-cyclic-partition-score/) · Tags: Array, Dynamic Programming

## 题意

给你一个 循环 数组 nums 和一个整数 k。 将 nums 划分 为 最多 k 个子数组。由于 nums 是循环数组，这些子数组可以从数组末尾环绕回起点。 子数组的 范围 定义为其 最大值 与 最小值 的差值。划分的 得分 是所有子数组范围的总和。 返回所有循环划分方案中可能获得的 最大得分 。 子数组 是数组中的一个连续非空的元素序列。 示例 1： 输…

## 最优思路

数组循环且至多分成 $k$ 段，得分是各段 $\max-\min$ 之和。 $n\le 1000$，可枚举循环断点把环拉直，再在线性数组上做「至多 $k$ 段、最大化极差和」的区间 DP。相邻段在断点处不共享元素。
