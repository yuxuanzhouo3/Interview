# LC 3704. Count No-Zero Pairs That Sum to N

> Hard · [LeetCode](https://leetcode.com/problems/count-no-zero-pairs-that-sum-to-n/) · Tags: Math, Digit DP

## 题意

统计 `a+b=n` 且 a,b 十进制表示不含数字 0 的正整数对数量。

## 最优思路

从低位到高位 digit DP：每位数字 1–9 或已结束为 0，匹配进位与目标和。

## 图解

```text
low-to-high digit DP
alive flags + carry
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(\\log n)$ |
| 空间 | $O(\\log n)$ |
