# LC 588. Design In-Memory File System

> Hard · [LeetCode](https://leetcode.com/problems/design-in-memory-file-system/) · Tags: Design, Trie, Hash Table

## 题意

实现内存文件系统：`ls` / `mkdir` / `addContentToFile` / `readContentFromFile`。

## 最优思路

字典树：节点含子目录与文件内容映射。`ls` 遇文件只返回文件名，否则返回排序后的目录+文件名。

## 图解

```text
/ → a/ → b/ → c/ → file d
ls("/")=["a"]; ls("/a/b/c/d")=["d"]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | 路径长度相关 |
| 空间 | 路径与文件内容 |
