# LC 564. Find the Closest Palindrome

> Hard · [LeetCode](https://leetcode.com/problems/find-the-closest-palindrome/) · Tags: Math, String

## 题意

给定数字字符串 `n`，求与之最接近的**回文数**（不能等于自身）。距离相同时取较小者。

## 最优思路

关键候选来自「前半截 ±1 再镜像」：

1. 前缀 `prefix`、`prefix±1` 镜像成回文
2. 边界：`10^{len-1}-1`（全 9）、`10^{len}+1`（1…0…1）
3. 去掉自身，按 `|diff|` 再按数值取最小

## 图解

```text
n = 123 → prefix=12 → 121 / 111 / 131
边界: 99, 1001
最近: 121
```
