# LC 552. Student Attendance Record II

> Hard · [LeetCode](https://leetcode.com/problems/student-attendance-record-ii/) · Tags: Dynamic Programming

## 题意

长度为 `n` 的出勤记录由 `A/L/P` 组成；可获奖当且仅当：**缺勤 A 少于 2 次**，且**不存在连续 3 个或以上 L**。求可获奖记录数，对 \(10^9+7\) 取模。

## 最优思路

状态 `dp[a][l]`：已用 `a` 次缺勤、当前结尾连续 `l` 个 L 的方案数。转移：

- 加 `P` → `(a, 0)`
- 加 `A`（`a<1`）→ `(a+1, 0)`
- 加 `L`（`l<2`）→ `(a, l+1)`

滚动一维即可。

## 图解

```text
状态 (a,l) --P--> (a,0)
           --A--> (a+1,0)  if a=0
           --L--> (a,l+1)  if l<2
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(1)\) |
