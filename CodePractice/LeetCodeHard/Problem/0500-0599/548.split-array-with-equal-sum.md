# LC 548. Split Array with Equal Sum

> Hard · [LeetCode](https://leetcode.com/problems/split-array-with-equal-sum/) · Premium · Tags: Array, Hash Table, Prefix Sum

## 题意

判断能否用三个切点把数组分成四段等和（切点元素不算入段和）。

## 最优思路

枚举中间切点 j；左侧枚举 i 把等和放入集合；右侧枚举 k 查是否命中。

## 图解

```text
Input → 前缀和 + 枚举中切，集合存左等分 → Answer
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(n²) |
| 空间 | O(n) |
