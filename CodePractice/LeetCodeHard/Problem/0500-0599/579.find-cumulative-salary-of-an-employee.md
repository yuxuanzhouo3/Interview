# LC 579. Find Cumulative Salary of an Employee

> Hard · [LeetCode](https://leetcode.com/problems/find-cumulative-salary-of-an-employee/) · Premium · Tags: Database

## 题意

每位员工排除最近一个月，对剩余月份输出「当月及前两个月」薪资之和。

## 最优思路

自连接取 Month 落在 [m-2,m]，并过滤每人最大 Month。

## 图解

```text
SQL 聚合 / 窗口 / 透视 → 结果表
```
