# LC 591. Tag Validator

> Hard · [LeetCode](https://leetcode.com/problems/tag-validator/) · Tags: String, Stack

## 题意

校验类 HTML 字符串：标签名 1–9 大写字母；可嵌套；支持 `<![CDATA[...]]>`；整体必须被一对标签包裹。

## 最优思路

线性扫描 + 栈：

- 遇 CDATA 跳到 `]]>`
- 遇结束标签弹出并匹配
- 遇开始标签压栈（校验名字）
- 非首字符处栈空则非法

## 图解

```text
<code> ... <![CDATA[...]]> ... </code>
  push              skip           pop/match
```
