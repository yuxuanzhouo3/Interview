# LC 174. Dungeon Game

> Hard · [LeetCode](https://leetcode.com/problems/dungeon-game/)

## 题意

骑士从左上到右下，血量始终 ≥1，求初始最小生命值。

## 最优思路

从终点逆推 `dp[i][j]`：进入该格前需要的最小 HP。

## 图解

```mermaid
flowchart RL
  End[princess] --> Cell[need = min(down,right) - dungeon]
  Cell --> Start
```
