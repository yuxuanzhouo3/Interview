# LC 154. Find Minimum in Rotated Sorted Array II

> Hard · [LeetCode](https://leetcode.com/problems/find-minimum-in-rotated-sorted-array-ii/)

## 题意

旋转有序数组（含重复）找最小值。

## 最优思路

二分：`nums[mid] > nums[hi]` 则最小在右；`<` 则在左含 mid；相等则 `hi--` 去重。

## 图解

```text
[2,2,2,0,1] → shrink hi when equal → 0
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | 最坏 \(O(n)\) |
| 空间 | \(O(1)\) |
