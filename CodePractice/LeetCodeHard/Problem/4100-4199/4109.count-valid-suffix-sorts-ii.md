# LC 4109. Count Valid Suffix Sorts II

> Hard · [LeetCode](https://leetcode.com/problems/count-valid-suffix-sorts-ii/) · Tags: —

## 题意

对每个起点 i，保留前缀 nums[0..i)，将后缀 nums[i..] 降序排序，得到长度为 n 的新数组。对 target 每个长度为 n 的窗口，统计有多少个 i 能得到该窗口。

## 最优思路

枚举 i 生成所有可能结果数组并计数；再对每个窗口查表。大数据可用后缀结构优化，样例规模直接枚举即可。

## 图解

```text
nums → 各 i 的「前缀+降序后缀」→ 频次表 → 扫 target 窗口
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(n^2 log n + (m-n)n) |
| 空间 | O(n^2) |
