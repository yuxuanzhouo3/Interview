# LC 4100. Minimum Cost Path With Even XOR Parity

> Hard · [LeetCode](https://leetcode.com/problems/minimum-cost-path-with-even-xor-parity/) · Tags: —

## 题意

树上两点路径的节点值 XOR 的二进制中 1 的个数为偶数时称为 Balanced-XOR，求这样路径的最小边权和；不存在返回 -1。

## 最优思路

枚举路径（小数据直接 DFS；大数据需结合 popcount 奇偶与树上前缀 XOR 做最值查询）。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```
