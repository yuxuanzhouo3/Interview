# LC 4105. Repeated String Match II

> Hard · [LeetCode](https://leetcode.com/problems/repeated-string-match-ii/) · Tags: —

## 题意

判断 b 重复 y 次是否为 a 重复 x 次的子串（x,y 可达 1e9）。

## 最优思路

长度先判；枚举 a 内对齐起点，用双周期一致性在 O(|a||b|) 内验证，并保证覆盖区间落在 a*x 内。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(|a|^2 |b|) |
| 空间 | O(1) |
