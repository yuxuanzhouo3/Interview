# LC 3320. Count The Number of Winning Sequences

> Hard · [LeetCode](https://leetcode.com/problems/count-the-number-of-winning-sequences/) · Tags: String, DP

## 题意

石头剪刀布变体 F/W/E；Bob 不能连续相同手势，求 Bob 净胜场 >0 的序列数。

## 最优思路

DP：`dp[last][score_diff]` 逐轮转移。

## 图解

```text
dp[last][diff] → next move ≠ last
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n^2)$ |
| 空间 | $O(n)$ |
