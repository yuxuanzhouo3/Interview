# LC 3369. Design an Array Statistics Tracker 

> Hard · [LeetCode](https://leetcode.com/problems/design-an-array-statistics-tracker/) · Tags: Hash Table, Binary Search, Design, Queue, Heap (Priority Queue), Data Stream, Ordered Set

## 题意

设计数据结构：支持队头删除、追加，并查询均值（下取整）、中位数、众数（频最高且值最小）。

## 最优思路

deque 保序；有序数组维护中位数；频率堆懒删除维护众数；总和维护均值。

## 图解

```text
deque + sorted arr + (-freq,val) heap
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(\log n)$/op（中位 $O(n)$ 插入可接受或用对顶堆） |
| 空间 | $O(n)$ |
