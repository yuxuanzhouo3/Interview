# LC 3373. Maximize the Number of Target Nodes After Connecting Trees II

> Hard · [LeetCode](https://leetcode.com/problems/maximize-the-number-of-target-nodes-after-connecting-trees-ii/) · Tags: Tree, BFS, Bipartite

## 题意

两棵树连一条边；目标节点 = 与选定节点距离为偶数的节点。对 tree1 每个节点求连边后最大目标数。

## 最优思路

树是二分图：偶距离 = 同色。tree2 贡献取两部较大者；tree1 取该点同色数量。

## 图解

```text
even dist = same color
ans[i] = same_color_count1 + max(part2)
```
