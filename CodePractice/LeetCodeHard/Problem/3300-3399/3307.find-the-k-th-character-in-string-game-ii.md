# LC 3307. Find the K-th Character in String Game II

> Hard · [LeetCode](https://leetcode.com/problems/find-the-k-th-character-in-string-game-ii/) · Tags: Math, Bit Manipulation, Recursion

## 题意

从字符 a 开始，每次把整串追加到末尾（op=0 原样，op=1 每位 +1）。求最终第 k 个字符。

## 最优思路

从后往前：若 k 落在后半，减去半长，若 op=1 则累计移位。

## 图解

```text
len doubles each op
if k in 2nd half: k-=half; shift+=op
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(\\log k)$ |
| 空间 | $O(1)$ |
