# LC 3352. Count K-Reducible Numbers Less Than N

> Hard · [LeetCode](https://leetcode.com/problems/count-k-reducible-numbers-less-than-n/) · Tags: Math, String, Dynamic Programming, Combinatorics

## 题意

二进制字符串 s 表示的整数 n：统计 < n 且至多 k 次「替换为二进制 1 的个数」能变成 1 的正整数个数。

## 最优思路

预处理 popcount 的归约步数；数位 DP 统计 bit 为 1 的个数，再判断 1+steps[ones]≤k；最后减去 s 本身（若合法）。

## 图解

```text
digit DP(pos,tight,ones) + steps[popcount]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(|s|^2)$ |
| 空间 | $O(|s|^2)$ |
