# LC 3399. Smallest Substring With Identical Characters II

> Hard · [LeetCode](https://leetcode.com/problems/smallest-substring-with-identical-characters-ii/) · Tags: String, Binary Search

## 题意

最多翻转 `numOps` 个字符，最小化「最长连续相同字符」长度。

## 最优思路

二分答案 mid：每段长度为 L 的 run 至少需 `L//(mid+1)` 次翻转切开。

## 图解

```text
binary search mid
ops += run_len // (mid+1)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n\\log n)$ |
| 空间 | $O(1)$ |
