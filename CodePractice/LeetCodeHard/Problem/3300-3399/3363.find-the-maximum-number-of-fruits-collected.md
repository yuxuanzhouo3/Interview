# LC 3363. Find the Maximum Number of Fruits Collected

> Hard · [LeetCode](https://leetcode.com/problems/find-the-maximum-number-of-fruits-collected/) · Tags: Array, DP, Matrix

## 题意

三人同时走 n-1 步收集水果且不重复格子：分别从 (0,0)/(0,n-1)/(n-1,0) 到 (n-1,n-1)。

## 最优思路

一人走主对角线；另两人分别在上/下三角 DP，避开对角线。

## 图解

```text
diag sum + DP upper + DP lower
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n^2)$ |
| 空间 | $O(n)$ |
