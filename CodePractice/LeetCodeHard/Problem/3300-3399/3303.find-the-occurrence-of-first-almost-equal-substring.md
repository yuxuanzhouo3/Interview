# LC 3303. Find the Occurrence of First Almost Equal Substring

> Hard · [LeetCode](https://leetcode.com/problems/find-the-occurrence-of-first-almost-equal-substring/) · Tags: String, String Matching, Knuth–Morris–Pratt Algorithm

## 题意

在 s 中找最短起点，使长度为 |pattern| 的子串与 pattern 最多差 1 个字符。

## 最优思路

对 pattern#s 与反串做 Z 函数；起点 i 合法当且仅当前缀匹配 + 后缀匹配 ≥ m-1。

## 图解

```text
Z(pattern#s)[i] + Z(rev)[i] ≥ m-1
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n+m)$ |
| 空间 | $O(n+m)$ |
