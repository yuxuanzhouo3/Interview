# LC 699. Falling Squares

> Hard · [LeetCode](https://leetcode.com/problems/falling-squares/) · Tags: Array, Segment Tree, Ordered Set

## 题意

方块依次从 `positions[i]=[left,side]` 落下，落到已有方块上叠高。每次落后返回当前最高高度序列。

## 最优思路

维护已落区间 `[L,R)` 高度；新方块取与之相交区间的最大高度为底座。n 较小时 \(O(n^2)\) 即可；更优用线段树。

## 图解

```text
[1,3) h=2
  [2,5) 底座2 → h=5
      [6,7) 无交 → h=1
全局高: 2,5,5
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2)\) |
| 空间 | \(O(n)\) |
