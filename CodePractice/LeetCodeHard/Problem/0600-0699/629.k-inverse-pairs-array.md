# LC 629. K Inverse Pairs Array

> Hard · [LeetCode](https://leetcode.com/problems/k-inverse-pairs-array/) · Tags: Dynamic Programming

## 题意

求由 `1..n` 组成的排列中，恰好有 `k` 个逆序对的个数，模 \(10^9+7\)。

## 最优思路

`dp[i][j]`：用 `1..i` 构成、逆序对为 `j` 的方案。插入 `i` 可产生 `0..i-1` 个新逆序：

\[
dp[i][j] = \sum_{t=0}^{\min(j,i-1)} dp[i-1][j-t]
\]

用前缀和优化到 \(O(nk)\)。

## 图解

```text
i=3: 插入 3 到位置 → 新逆序 0/1/2
dp[3][j] = dp[2][j]+dp[2][j-1]+dp[2][j-2]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(nk)\) |
| 空间 | \(O(k)\) |
