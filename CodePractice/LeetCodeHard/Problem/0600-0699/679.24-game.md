# LC 679. 24 Game

> Hard · [LeetCode](https://leetcode.com/problems/24-game/) · Tags: Array, Math, Backtracking

## 题意

四张牌，用 `+ - * /` 与括号运算，判断能否得到 24（除法为实数除）。

## 最优思路

回溯：任选两数做四则运算，结果放回继续，直到只剩一数，判断是否接近 24。

## 图解

```text
[a,b,c,d] → 选 a,b 得 x → [x,c,d] → ... → [24?]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(1)\)（4 张牌） |
| 空间 | \(O(1)\) |
