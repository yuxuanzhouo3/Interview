# LC 668. Kth Smallest Number in Multiplication Table

> Hard · [LeetCode](https://leetcode.com/problems/kth-smallest-number-in-multiplication-table/) · Tags: Math, Binary Search

## 题意

`m×n` 乘法表中第 `k` 小的数。

## 最优思路

对值二分：`count(≤x) = Σ_i min(n, x//i)`，找最小使计数 ≥k 的 `x`。

## 图解

```text
3x3: 1 2 3 / 2 4 6 / 3 6 9
第5小 = 3
```

## 复杂度

| 时间 | \(O(m\log(mn))\) |
| 空间 | \(O(1)\) |
