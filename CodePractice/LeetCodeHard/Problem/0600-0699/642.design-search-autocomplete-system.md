# LC 642. Design Search Autocomplete System

> Hard · [LeetCode](https://leetcode.com/problems/design-search-autocomplete-system/) · Tags: String, Design, Trie

## 题意

实现自动补全：历史句子带热度；逐字符输入，返回当前前缀下热度最高的 3 句（同热度字典序）；`#` 结束并计入历史。

## 最优思路

哈希表存频次；每次按前缀过滤后 `(-freq, s)` 排序取前 3。数据量大可用 Trie + 节点热句列表优化。

## 图解

```text
input 'i' → 匹配 "i ..." → top3 by hot
input '#' → freq[cur]++，清空缓冲
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | 每次 \(O(N\log N)\)（朴素） |
| 空间 | \(O(\sum |s|)\) |
