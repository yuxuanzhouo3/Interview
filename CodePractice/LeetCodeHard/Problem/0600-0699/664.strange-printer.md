# LC 664. Strange Printer

> Hard · [LeetCode](https://leetcode.com/problems/strange-printer/) · Tags: String, Dynamic Programming

## 题意

奇怪打印机每次可在连续区间印同一字符（可覆盖），求印出字符串的最少次数。

## 最优思路

区间 DP：`dp[i][j]` 印出 `s[i..j]` 最少次数。压缩相邻相同字符后：

- 先印 `s[i]`，再处理剩余
- 若 `s[k]==s[i]`，可合并一次打印

## 图解

```text
s[i]==s[k] → dp[i][j] = dp[i][k-1] + dp[k+1][j]
（同一笔画覆盖两端）
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^3)\) |
| 空间 | \(O(n^2)\) |
