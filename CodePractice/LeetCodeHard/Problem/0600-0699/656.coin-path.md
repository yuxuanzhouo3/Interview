# LC 656. Coin Path

> Hard · [LeetCode](https://leetcode.com/problems/coin-path/) · Tags: Array, Dynamic Programming

## 题意

数组 `coins`（负值不可达），从下标 0 跳到末尾，每次最多跳 `maxJump` 步，代价为路径上正硬币之和。求**代价最小**且字典序最小的 1-indexed 路径。

## 最优思路

从右往左 DP：`cost[i]`、`next[i]`。相等代价时选更小下一跳以保证字典序。

## 图解

```text
i → 可选 j∈(i, i+B] → 取 cost 最小 / next 更小
回溯 next 得路径
```
