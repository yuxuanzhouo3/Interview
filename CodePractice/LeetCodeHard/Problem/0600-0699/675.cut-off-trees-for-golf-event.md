# LC 675. Cut Off Trees for Golf Event

> Hard · [LeetCode](https://leetcode.com/problems/cut-off-trees-for-golf-event/) · Tags: Array, BFS, Matrix

## 题意

从 `(0,0)` 出发，按树高升序砍光所有树（值>1），`0` 不可走。求最少步数，不可达返回 -1。

## 最优思路

按高度排序树；相邻目标之间 BFS 最短路，累加步数。

## 图解

```text
(0,0) --BFS--> 最矮树 --BFS--> 次矮 ...
```

## 复杂度

| 时间 | \(O(t\cdot mn)\) |
| 空间 | \(O(mn)\) |
