# LC 3187. Peaks in Array

> Hard · [LeetCode](https://leetcode.com/problems/peaks-in-array/) · Tags: Array, Binary Indexed Tree, Segment Tree

## 题意

维护数组峰（严格大于左右），支持改点与查询开区间内峰个数。

## 最优思路

树状数组存峰；更新影响 `idx-1,idx,idx+1`。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O((n+q)\log n)\) |
| 空间 | \(O(n)\) |
