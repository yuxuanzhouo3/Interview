# LC 3123. Find Edges in Shortest Paths

> Hard · [LeetCode](https://leetcode.com/problems/find-edges-in-shortest-paths/) · Tags: Graph, Shortest Path, Heap

## 题意

无向带权图，判断每条边是否出现在某条 0→n-1 最短路上。

## 最优思路

分别从 0 与 n-1 Dijkstra。边 `(u,v,w)` 在最短路上 iff `d0[u]+w+dn[v]==d0[n-1]` 或对称。

## 图解

```text
d0[u] + w + dn[v] == dist(0,n-1)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O((n+m)\\log n)$ |
| 空间 | $O(n+m)$ |
