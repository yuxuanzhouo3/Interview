# LC 3193. Count the Number of Inversions

> Hard · [LeetCode](https://leetcode.com/problems/count-the-number-of-inversions/) · Tags: Array, Dynamic Programming

## 题意

统计长度为 `n` 的排列数，满足若干前缀逆序对个数约束，模 \(10^9+7\)。

## 最优思路

逐位插入最大值：`dp[i][j]` 转移为前缀和；遇约束只保留对应 `j`。

## 图解

```mermaid
flowchart LR
  A[dp 前缀逆序] --> B[插入新最大值]
  B --> C[应用 requirements]
```
