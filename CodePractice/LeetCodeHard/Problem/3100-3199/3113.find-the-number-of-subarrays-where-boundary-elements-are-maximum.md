# LC 3113. Find the Number of Subarrays Where Boundary Elements Are Maximum

> Hard · [LeetCode](https://leetcode.com/problems/find-the-number-of-subarrays-where-boundary-elements-are-maximum/) · Tags: Array, Stack, Monotonic Stack

## 题意

统计满足「两端元素等于子数组最大值」的子数组个数。

## 最优思路

从左扫描，单调栈维护严格递减的「当前可见最大值」段。对每个右端点，可向左延伸的合法左端点数等于栈顶同值连续段长度。

## 图解

```text
stack: decreasing maxima
for each x: pop < x; count equal run; ans += run
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n)$ |
| 空间 | $O(n)$ |
