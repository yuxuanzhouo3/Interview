# LC 3130. Find All Possible Stable Binary Arrays II

> Hard · [LeetCode](https://leetcode.com/problems/find-all-possible-stable-binary-arrays-ii/) · Tags: DP, Prefix Sum

## 题意

含 `zero` 个 0、`one` 个 1，且连续相同位不超过 `limit` 的数组个数。

## 最优思路

DP 按结尾块转移：以 0/1 结尾的方案，块长 1..limit。

## 图解

```text
dp0/dp1 by last block length ≤ limit
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(zero\\cdot one\\cdot limit)$ |
| 空间 | $O(zero\\cdot one)$ |
