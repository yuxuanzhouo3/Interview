# LC 3161. Block Placement Queries

> Hard · [LeetCode](https://leetcode.com/problems/block-placement-queries/) · Tags: Array, Binary Indexed Tree, Ordered Set

## 题意

数轴上放障碍；查询能否在 `[0,x]` 内放入长度为 `sz` 的块（不与障碍重叠）。

## 最优思路

倒序处理：先放齐所有障碍，用有序集合维护位置，树状数组维护「到某位置为止的最大空隙」；删除障碍时合并空隙。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log X)\) |
| 空间 | \(O(X)\) |
