# LC 3181. Maximum Total Reward Using Operations II

> Hard · [LeetCode](https://leetcode.com/problems/maximum-total-reward-using-operations-ii/) · Tags: Array, DP, Bitset

## 题意

每次选一个尚未选过且严格大于当前总分的奖励加入总分，求最大总分。

## 最优思路

bitset DP：可达成和的集合；对值 x，把 `<x` 的和整体 `+x`。

## 图解

```text
bits |= (bits & ((1<<x)-1)) << x
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n \\cdot M / w)$ |
| 空间 | $O(M/w)$ |
