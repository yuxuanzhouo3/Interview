# LC 3134. Find the Median of the Uniqueness Array

> Hard · [LeetCode](https://leetcode.com/problems/find-the-median-of-the-uniqueness-array/) · Tags: Array, Binary Search, Sliding Window

## 题意

对所有子数组求「不同元素个数」得到 uniqueness 数组，返回其（排序后的）中位数。

## 最优思路

二分中位数值 m：滑动窗口统计「不同元素 ≤ m」的子数组个数，与中位序比较。

## 图解

```text
binary search m
at_most(m) >= median_rank ?
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n \\log U)$ |
| 空间 | $O(n)$ |
