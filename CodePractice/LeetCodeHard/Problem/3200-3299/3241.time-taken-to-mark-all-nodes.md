# LC 3241. Time Taken to Mark All Nodes

> Hard · [LeetCode](https://leetcode.com/problems/time-taken-to-mark-all-nodes/) · Tags: Dynamic Programming, Tree, Depth-First Search, Graph Theory, DP on Trees

## 题意

无向树；奇数节点标记延迟 1，偶数延迟 2。对每个起点，返回整棵树全部标记的时间。

## 最优思路

边权为进入目标节点的代价。等价于对每个点求加权最远距离，用两次 DFS 换根 DP：向下最优/次优，再推向上路径。

## 图解

```text
down[u]=max over children (cost(v)+down[v])
up[v]=cost(u)+max(up[u], sibling_best)
ans[u]=max(down[u], up[u])
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n)$ |
| 空间 | $O(n)$ |
