# LC 3288. Length of the Longest Increasing Path

> Hard · [LeetCode](https://leetcode.com/problems/length-of-the-longest-increasing-path/) · Tags: Array, Binary Search, Sorting, Longest Increasing Subsequence

## 题意

二维点集中，必须经过 coordinates[k]，求严格 x、y 都递增的最长路径长度。

## 最优思路

拆成 k 左侧 (x<kx,y<ky) 与右侧；各自按 x 排序后对 y 做 LIS（同 x 批处理），答案 = 左 LIS + 1 + 右 LIS。

## 图解

```text
left pts → LIS(y) + 1 + right LIS(y)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n \log n)$ |
| 空间 | $O(n)$ |
