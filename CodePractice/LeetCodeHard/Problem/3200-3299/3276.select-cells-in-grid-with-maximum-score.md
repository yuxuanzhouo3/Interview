# LC 3276. Select Cells in Grid With Maximum Score

> Hard · [LeetCode](https://leetcode.com/problems/select-cells-in-grid-with-maximum-score/) · Tags: Array, Dynamic Programming, Bit Manipulation, Matrix, Bitmask

## 题意

给你一个由正整数构成的二维矩阵 grid。 你需要从矩阵中选择 一个或多个 单元格，选中的单元格应满足以下条件： 所选单元格中的任意两个单元格都不会处于矩阵的 同一行。 所选单元格的值 互不相同。 你的得分为所选单元格值的总和。 返回你能获得的 最大 得分。 &nbsp;

## 最优思路

我们定义 $f[i][j]$ 表示在 $[1,..i]$ 的数中进行选择，且选择的数对应的行的状态为 $j$ 时的最大得分。初始时 $f[i][j] = 0$，答案为 $f[mx][2^m - 1]$。其中 $mx$ 表示矩阵中的最大值，而 $m$ 表示矩阵的行数。 我们首先对矩阵进行预处理，使用一个哈希表 $g$ 记录每个数对应的行的集合。然后我们可以使用状态压缩动态规划的方法求解答案。 对于状态 $f[i][j]$，我们可以不选择 $i$ 这个数，此时 $f[i][j] = f[i-1][j]$；也可以选择 $i$ 这个数，此时我们需要枚举 $i$ 对应的行的集合 $g[i]$ 中的每一个行 $k$，如果 $j$ 的第 $k$ 位为 $1$，则说明我们可以选择 $i$ 这个数，此时 $f[i][j] = \max(f[i][j], f[i-1][j \oplus 2^k] + i)$。 最后我们返回 $f[mx][2^m - 1]$ 即可。
