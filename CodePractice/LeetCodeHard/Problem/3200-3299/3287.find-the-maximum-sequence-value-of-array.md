# LC 3287. Find the Maximum Sequence Value of Array

> Hard · [LeetCode](https://leetcode.com/problems/find-the-maximum-sequence-value-of-array/) · Tags: Array, Dynamic Programming, Bit Manipulation

## 题意

给你一个整数数组&nbsp;nums&nbsp;和一个 正&nbsp;整数&nbsp;k&nbsp;。 定义长度为 2 * x&nbsp;的序列 seq&nbsp;的 值&nbsp;为： (seq[0] OR seq[1] OR ... OR seq[x - 1]) XOR (seq[x] OR seq[x + 1] OR ... OR seq[2 * x - 1]). 请你求出 nums&nbsp;中所有长度为 2 * k&nbsp;…

## 最优思路

我们考虑将序列分成两部分，前 $k$ 个元素和后 $k$ 个元素，分别计算前后缀的所有可能的异或值。 定义 $f[i][j][x]$ 表示前 $i$ 个元素中取 $j$ 个元素，是否存在一个子集的异或值为 $x$，定义 $g[i][j][y]$ 表示从下标 $i$ 开始取 $j$ 个元素，是否存在一个子集的异或值为 $y$。 考虑 $f[i][j][x]$ 的转移方程，对于第 $i$ 个元素（从 $0$ 开始），我们可以选择不取，也可以选择取，因此有： $$ f[i + 1][j][x] = f[i + 1][j][x] \lor f[i][j][x] \\ f[i + 1][j + 1][x \lor \textit{nums}[i]] = f[i + 1][j + 1][x \lor \textit{nums}[i]] \lor f[i][j][x] $$ 对于 $g[i][j][y]$ 的转移方程，同样对于第 $i$ 个元素（从 $n - 1$ 开始），我们可以选择不取，也可以选择…
