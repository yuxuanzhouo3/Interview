# LC 3250. Find the Count of Monotonic Pairs I

> Hard · [LeetCode](https://leetcode.com/problems/find-the-count-of-monotonic-pairs-i/) · Tags: Array, DP, Prefix Sum

## 题意

与 3251 相同题意，约束较小：构造单调对 `(arr1非降, arr2非增)` 且逐位和为 nums。

## 最优思路

DP `arr1` 取值 + 前缀和加速转移。

## 图解

```text
dp[v] via prefix of previous
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(nM)$ |
| 空间 | $O(M)$ |
