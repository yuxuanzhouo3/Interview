# LC 3235. Check if the Rectangle Corner Is Reachable

> Hard · [LeetCode](https://leetcode.com/problems/check-if-the-rectangle-corner-is-reachable/) · Tags: Geometry, Union-Find

## 题意

在矩形内从左下到右上，不进入圆形障碍；判断是否可达。

## 最优思路

圆与圆、圆与边界建连通；若「左/上」与「下/右」被圆连通则阻断。

## 图解

```text
UF circles + borders
LEFT_TOP connected BOTTOM_RIGHT → blocked
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n^2)$ |
| 空间 | $O(n)$ |
