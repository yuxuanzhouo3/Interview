# LC 3231. Minimum Number of Increasing Subsequence to Be Removed

> Hard · [LeetCode](https://leetcode.com/problems/minimum-number-of-increasing-subsequence-to-be-removed/) · Tags: Array, Binary Search

## 题意

每次删除一个严格递增子序列，最少删多少次使数组为空。

## 最优思路

Dilworth：最少递增子序列覆盖数 = 最长非严格递减子序列长度。用耐心排序 / 二分维护 tails。

## 图解

```text
cover by ↑ subsequences ⇔ LDS length
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n \log n)$ |
| 空间 | $O(n)$ |
