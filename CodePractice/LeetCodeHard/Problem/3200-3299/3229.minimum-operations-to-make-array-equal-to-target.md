# LC 3229. Minimum Operations to Make Array Equal to Target

> Hard · [LeetCode](https://leetcode.com/problems/minimum-operations-to-make-array-equal-to-target/) · Tags: Array, Greedy

## 题意

每次可将子数组整体 +1 或 -1，使 nums 变成 target 的最少操作次数。

## 最优思路

令 `d=target-nums`。子数组加减对应差分。答案 = `d` 中相对前缀新增加的正增量之和。

## 图解

```text
d = target - nums
ans += max(0, d[i]-d[i-1])
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n)$ |
| 空间 | $O(1)$ |
