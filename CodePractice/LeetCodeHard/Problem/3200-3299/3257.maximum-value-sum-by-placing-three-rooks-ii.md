# LC 3257. Maximum Value Sum by Placing Three Rooks II

> Hard · [LeetCode](https://leetcode.com/problems/maximum-value-sum-by-placing-three-rooks-ii/) · Tags: Array, Dynamic Programming, Matrix, Enumeration

## 题意

在棋盘放三只互不攻击的车，最大化格子值和。

## 最优思路

每行保留最大 3 个格子，枚举三行再匹配不同列。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(m n + m^3)\) |
| 空间 | \(O(m)\) |
