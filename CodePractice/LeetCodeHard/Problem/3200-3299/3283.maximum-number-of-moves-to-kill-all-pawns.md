# LC 3283. Maximum Number of Moves to Kill All Pawns

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-moves-to-kill-all-pawns/) · Tags: Array, Math, Bit Manipulation, Breadth-First Search, Game Theory, Bitmask

## 题意

给你一个&nbsp;50 x 50&nbsp;的国际象棋棋盘，棋盘上有 一个&nbsp;马和一些兵。给你两个整数&nbsp;kx 和&nbsp;ky&nbsp;，其中&nbsp;(kx, ky)&nbsp;表示马所在的位置，同时还有一个二维数组&nbsp;positions&nbsp;，其中&nbsp;positions[i] = [xi, yi]&nbsp;表示第 i&nbsp;个兵在棋盘上的位置。 Alice 和 Bob 玩一个回合…

## 最优思路

我们首先预处理出每个兵到棋盘上任意一个位置的马的最短距离，记录在数组 $\textit{dist}$ 中，即 $\textit{dist}[i][x][y]$ 表示第 $i$ 个兵到 $(x, y)$ 位置的马的最短距离。 接下来，我们设计一个函数 $\textit{dfs}(\textit{last}, \textit{state}, k)$，其中 $\textit{last}$ 表示上一个吃掉的兵的编号，而 $\textit{state}$ 表示当前还剩下的兵的状态，而 $k$ 表示当前是 Alice 还是 Bob 的回合。函数的返回值表示当前回合的最大移动次数。那么答案为 $\textit{dfs}(n, 2^n-1, 1)$。这里我们初始时上一个吃掉的兵的编号记为 $n$，这也是马所在的位置。 函数 $\textit{dfs}$ 的具体实现如下： - 如果 $\textit{state} = 0$，表示没有兵了，返回 $0$； - 如果 $k = 1$，表示当前是 Alice 的…
