# LC 2709. Greatest Common Divisor Traversal

> Hard · [LeetCode](https://leetcode.com/problems/greatest-common-divisor-traversal/) · Tags: Math, Union-Find, Number Theory

## 题意

若 `gcd(nums[i],nums[j])>1` 可互达；问是否所有下标连通。

## 最优思路

按质因数并查集：共享质因数的下标合并；含 `1` 且 `n>1` 则失败。

## 图解

```text
index --prime--> same component
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\sqrt{A})\) |
| 空间 | \(O(n+\pi)\) |
