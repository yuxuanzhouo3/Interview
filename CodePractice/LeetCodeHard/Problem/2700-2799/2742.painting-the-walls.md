# LC 2742. Painting the Walls

> Hard · [LeetCode](https://leetcode.com/problems/painting-the-walls/) · Tags: DP, Knapsack

## 题意

付费油漆工刷墙 `i` 耗时 `time[i]`、费用 `cost[i]`；同时免费工可刷其他墙。求刷完所有墙最小费用。

## 最优思路

选一批付费墙：覆盖量 = `Σ(time[i]+1)`（自己 + 免费工刷的）。0-1 背包求覆盖 ≥ n 的最小费用。

## 图解

```text
item i: cost=c, weight=time+1
min cost s.t. weight ≥ n
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2)\) |
| 空间 | \(O(n)\) |
