# LC 2781. Length of the Longest Valid Substring

> Hard · [LeetCode](https://leetcode.com/problems/length-of-the-longest-valid-substring/) · Tags: String, Sliding Window, Hash

## 题意

`forbidden` 中串长 ≤10；求 `word` 中不含任何禁用子串的最长子串长度。

## 最优思路

从右往左扩左端点；检查以 `i` 开头、长度 ≤10 的前缀是否命中禁用，收紧右边界。

## 图解

```text
i → ... <right
check word[i..i+L) ∈ ban → shrink right
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\cdot 10^2)\) |
| 空间 | \(O(|\mathrm{forbidden}|)\) |
