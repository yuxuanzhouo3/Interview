# LC 2791. Count Paths That Can Form a Palindrome in a Tree

> Hard · [LeetCode](https://leetcode.com/problems/count-paths-that-can-form-a-palindrome-in-a-tree/) · Tags: Hash Table, Bit Manipulation, Tree, Depth-First Search

## 题意

树上边带小写字母，统计有多少对结点路径字母可重排成回文。

## 最优思路

路径异或掩码（每位奇偶）。可回文 ⟺ 掩码为 0 或恰 1 位为 1。DFS 用 Counter 统计祖先掩码贡献。

## 图解

```text
mask(u)^mask(v) 可回文
对当前 x：查 cnt[x] 与 cnt[x^(1<<k)]
```
