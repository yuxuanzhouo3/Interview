# LC 2790. Maximum Number of Groups With Increasing Length

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-groups-with-increasing-length/) · Tags: Array, Math, Binary Search, Greedy, Sorting

## 题意

第 `i` 类最多用 `usageLimits[i]` 次；构造尽量多组，使第 `j` 组恰好 `j` 个**互不相同**元素。求最大组数。

## 最优思路

排序后贪心：累计总量，若 `total ≥ 1+…+(ans+1)` 则可多一组。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log n)\) |
| 空间 | \(O(1)\) |
