# LC 2118. Build the Equation

> Hard · [LeetCode](https://leetcode.com/problems/build-the-equation/) · Premium · Tags: Database

## 题意

把 Terms(factor,power) 拼成多项式字符串 '...=0'。

## 最优思路

按 power 降序 GROUP_CONCAT，处理符号与 X/X^n 简写。

## 图解

```text
3X^2-X+2=0
```
