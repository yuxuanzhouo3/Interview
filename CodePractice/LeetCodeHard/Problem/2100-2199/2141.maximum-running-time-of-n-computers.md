# LC 2141. Maximum Running Time of N Computers

> Hard · [LeetCode](https://leetcode.com/problems/maximum-running-time-of-n-computers/) · Tags: Array, Binary Search, Greedy, Sorting

## 题意

`n` 台电脑同时运行，电池可任意切换。求最长同时运行分钟数。

## 最优思路

二分时间 `t`：每块电池最多贡献 `min(b,t)`，总和 ≥ `n*t` 即可。

## 图解

```text
多余电量（>t）浪费；总可用电量摊到 n 台
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(m\log(\sum b/n))\) |
| 空间 | \(O(1)\) |
