# LC 2179. Count Good Triplets in an Array

> Hard · [LeetCode](https://leetcode.com/problems/count-good-triplets-in-an-array/) · Tags: Array, Binary Search, Divide and Conquer, Binary Indexed Tree, Segment Tree, Merge Sort, Ordered Set

## 题意

在两个排列中位置都递增的三元组个数。

## 最优思路

把 `nums1` 映到 `nums2` 中的下标序列 `arr`；对每个中点，BIT 统计左侧更小、右侧更大。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log n)\) |
| 空间 | \(O(n)\) |
