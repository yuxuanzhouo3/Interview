# LC 2102. Sequentially Ordinal Rank Tracker

> Hard · [LeetCode](https://leetcode.com/problems/sequentially-ordinal-rank-tracker/) · Tags: Design, Heap (Priority Queue), Data Stream, Ordered Set

## 题意

按分数降序、同分名字升序维护景点；第 `i` 次 `get` 返回当前第 `i` 好的景点。

## 最优思路

`SortedList` 存 `(-score, name)`，用递增下标取第 `idx` 个。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(\log n)\) / 次 |
| 空间 | \(O(n)\) |
