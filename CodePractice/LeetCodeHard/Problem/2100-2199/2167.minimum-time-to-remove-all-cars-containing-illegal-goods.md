# LC 2167. Minimum Time to Remove All Cars Containing Illegal Goods

> Hard · [LeetCode](https://leetcode.com/problems/minimum-time-to-remove-all-cars-containing-illegal-goods/) · Tags: String, Dynamic Programming

## 题意

二进制串：`1` 为非法车厢。可从左删一端（1）、从右删一端（1）、或任意位置删一个非法车厢（2）。求删光所有非法车厢的最少时间。

## 最优思路

最优策略等价于：左侧某前缀用「左删 / 单独删」混合清掉，右侧后缀整段右删。`dp` = 清前缀 `s[:i+1]` 的最小代价；遇 `1` 取 `min(dp+2, i+1)`。答案 `min(dp + n-1-i)`。
