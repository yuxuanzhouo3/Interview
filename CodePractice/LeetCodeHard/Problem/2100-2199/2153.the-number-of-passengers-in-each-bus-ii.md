# LC 2153. The Number of Passengers in Each Bus II

> Hard · [LeetCode](https://leetcode.com/problems/the-number-of-passengers-in-each-bus-ii/) · Premium · Tags: Database

## 题意

公交车按到达顺序载客（有容量），未上车乘客可等下一辆，求每车载客数。

## 最优思路

按 bus 到达序递推：已到达人数 - 已上车人数，再与 capacity 取 min。

## 图解

```text
leftover → next bus
```
