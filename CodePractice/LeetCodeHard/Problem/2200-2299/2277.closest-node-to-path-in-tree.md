# LC 2277. Closest Node to Path in Tree

> Hard · [LeetCode](https://leetcode.com/problems/closest-node-to-path-in-tree/) · Tags: Array, Tree, Depth-First Search, Breadth-First Search

## 题意

树上查询：对路径 start–end，找距给定 node 最近且落在该路径上的点。

## 最优思路

倍增 LCA 判断点是否在路径上；从 node BFS，第一个落在路径上的点即答案。

## 图解

```text
path(start,end) —— closest hit from node via BFS
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(q\cdot n)\) 最坏（可优化） |
| 空间 | \(O(n\log n)\) |
