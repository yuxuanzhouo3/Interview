# LC 2218. Maximum Value of K Coins From Piles

> Hard · [LeetCode](https://leetcode.com/problems/maximum-value-of-k-coins-from-piles/) · Tags: DP, Prefix Sum

## 题意

每堆只能从顶部连续取；共取 `k` 枚；求最大价值和。

## 最优思路

分组背包：每堆前缀和为物品组；`dp[j]` = 取 j 枚最大价值。

## 图解

```text
dp'[j+t] = dp[j] + prefix[t]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(k\sum |pile|)\) |
| 空间 | \(O(k)\) |
