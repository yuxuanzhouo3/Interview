# LC 2213. Longest Substring of One Repeating Character

> Hard · [LeetCode](https://leetcode.com/problems/longest-substring-of-one-repeating-character/) · Tags: Segment Tree, String

## 题意

单点改字符后，求最长相同字符子串长度。

## 最优思路

线段树节点存 pref/suf/best，跨中点合并。

## 图解

```text
L.suf + R.pref 若边界字符相同
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O((n+k) log n) |
| 空间 | O(n) |
