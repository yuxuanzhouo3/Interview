# LC 2253. Dynamic Unpivoting of a Table

> Hard · [LeetCode](https://leetcode.com/problems/dynamic-unpivoting-of-a-table/) · Tags: Database

## 题意

宽表 `Products`（`product_id` + 若干未知 store 列）反透视成长表 `(product_id, store, price)`。

## 最优思路

从 `INFORMATION_SCHEMA.COLUMNS` 读列名，动态拼 `UNION ALL` 的 `SELECT`，再执行。

## 图解

```text
product_id | A | B
    →
product_id | store | price
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
