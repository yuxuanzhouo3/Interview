# LC 2272. Substring With Largest Variance

> Hard · [LeetCode](https://leetcode.com/problems/substring-with-largest-variance/) · Tags: String, Kadane

## 题意

子串 variance = 最高频字符次数 − 最低频字符次数；求最大 variance。

## 最优思路

枚举 `(a,b)` 作最多/最少字符；类 Kadane 维护 `cnt(a)-cnt(b)`，且子串必须含 `b`。

## 图解

```text
a→+1, b→-1 ; reset when bal<0 if more b remains
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(26^2 n)\) |
| 空间 | \(O(1)\) |
