# LC 2286. Booking Concert Tickets in Groups

> Hard · [LeetCode](https://leetcode.com/problems/booking-concert-tickets-in-groups/) · Tags: Binary Search, Design, Binary Indexed Tree, Segment Tree

## 题意

`n` 排各 `m` 座：`gather` 同一排连续座位；`scatter` 从前到后任意空位。返回座位或能否。

## 最优思路

线段树维护每排剩余座位和与区间最大剩余；gather 找首个剩余≥k 的排；scatter 查前缀和足够后顺序扣减。

## 图解

```text
gather: 查 max≥k 的最左排
scatter: sum≥k 则从左清空
```

## 复杂度

| 项 | 值 |
|----|----|
| gather | \(O(\log n)\) |
| scatter | 最坏 \(O(n)\) |
