# LC 2263. Make Array Non-decreasing or Non-increasing

> Hard · [LeetCode](https://leetcode.com/problems/make-array-non-decreasing-or-non-increasing/) · Tags: Array, Dynamic Programming, Greedy, Heap (Priority Queue)

## 题意

每次将元素 +1/-1，求使数组非降或非增的最少操作数。

## 最优思路

对最终值做 DP：`f[i][j]` 为前 i 个、第 i 个变成 j 的最小代价；反向数组覆盖非增。

## 图解

```text
f[i][j] = min_{k<=j} f[i-1][k] + |nums[i]-j|
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\cdot V)\) |
| 空间 | \(O(n\cdot V)\) |
