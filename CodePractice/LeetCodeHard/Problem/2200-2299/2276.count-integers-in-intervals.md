# LC 2276. Count Integers in Intervals

> Hard · [LeetCode](https://leetcode.com/problems/count-integers-in-intervals/) · Tags: Design, Segment Tree, Ordered Set

## 题意

动态加入闭区间并合并，查询当前覆盖的整数个数。

## 最优思路

有序表维护不相交区间；加入时合并重叠/相邻段并更新覆盖长度。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(k\log n)\)（k 为合并段数） |
| 空间 | \(O(n)\) |
