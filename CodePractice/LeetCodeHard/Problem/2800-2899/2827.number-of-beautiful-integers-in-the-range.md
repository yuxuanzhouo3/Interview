# LC 2827. Number of Beautiful Integers in the Range

> Hard · [LeetCode](https://leetcode.com/problems/number-of-beautiful-integers-in-the-range/) · Tags: Math, Dynamic Programming

## 题意

统计 `[low, high]` 中偶数位个数等于奇数位个数且能被 `k` 整除的数。

## 最优思路

数位 DP：状态 `(pos, even-odd, mod, tight, started)`。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(L\cdot L\cdot k)\) |
| 空间 | 同阶 |
