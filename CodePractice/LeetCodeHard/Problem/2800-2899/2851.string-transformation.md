# LC 2851. String Transformation

> Hard · [LeetCode](https://leetcode.com/problems/string-transformation/) · Tags: Math, String, Dynamic Programming, String Matching

## 题意

把 s 循环左移（真后缀前置）恰好 k 次变成 t 的方案数。

## 最优思路

KMP 找所有匹配旋转；旋转图上用闭式 `(n-1)^k` 与容斥得到到各起点的方案。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n+\log k)\) |
| 空间 | \(O(n)\) |
