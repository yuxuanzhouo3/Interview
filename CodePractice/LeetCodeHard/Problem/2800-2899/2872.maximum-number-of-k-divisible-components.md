# LC 2872. Maximum Number of K-Divisible Components

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-k-divisible-components/) · Tags: Tree, DFS

## 题意

删边把树分成若干连通块，每块节点值之和能被 `k` 整除；求最多块数。

## 最优思路

DFS 子树和；若 `%k==0` 则切下一块并向上贡献 0。

## 图解

```text
subtree_sum % k == 0 → +1 component
```
