# LC 2846. Minimum Edge Weight Equilibrium Queries in a Tree

> Hard · [LeetCode](https://leetcode.com/problems/minimum-edge-weight-equilibrium-queries-in-a-tree/) · Tags: Array, Dynamic Programming, Bit Manipulation, Tree, Depth-First Search

## 题意

树上边权查询：把 u–v 路径上所有边权变为同一值的最少修改次数。

## 最优思路

LCA + 根到点的权值频次数组差分，答案 = 路径边数 − 众数频次。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O((n+q)\log n)\) |
| 空间 | \(O(n\log n)\) |
