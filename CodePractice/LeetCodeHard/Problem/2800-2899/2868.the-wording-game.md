# LC 2868. The Wording Game

> Hard · [LeetCode](https://leetcode.com/problems/the-wording-game/) · Tags: Array, Math, Two Pointers, String, Greedy, Game Theory

## 题意

Alice/Bob 用词进行字典序严格递增博弈，Alice 先手，判断 Alice 是否必胜。

## 最优思路

每字母保留最大词；枚举 Alice 首步后双方贪心出更大词。

## 图解

```text
max word per first letter → greedy duel
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(\\Sigma^2)\) |
| 空间 | \(O(\\Sigma)\) |
