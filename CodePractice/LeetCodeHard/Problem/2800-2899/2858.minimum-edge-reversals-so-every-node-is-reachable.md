# LC 2858. Minimum Edge Reversals So Every Node Is Reachable

> Hard · [LeetCode](https://leetcode.com/problems/minimum-edge-reversals-so-every-node-is-reachable/) · Tags: Dynamic Programming, Depth-First Search, Breadth-First Search, Graph Theory

## 题意

有向树边；对每个点求最少翻转次数，使从该点能到达所有点。

## 最优思路

一次 DFS 算根 0 的翻转数，换根转移。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
