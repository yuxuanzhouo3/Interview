# LC 2836. Maximize Value of Function in a Ball Passing Game

> Hard · [LeetCode](https://leetcode.com/problems/maximize-value-of-function-in-a-ball-passing-game/) · Tags: Array, Dynamic Programming, Bit Manipulation

## 题意

功能图传球：选起点，沿 `receiver` 传 k 次，最大化路径节点编号之和（含起点）。

## 最优思路

倍增：`up[j][i]` / `sm[j][i]` 表示从 i 走 2^j 步的终点与编号和。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log k)\) |
| 空间 | \(O(n\log k)\) |
