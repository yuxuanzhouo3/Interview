# LC 76. Minimum Window Substring

> Hard · [LeetCode](https://leetcode.com/problems/minimum-window-substring/)

## 题意

在 `s` 中找覆盖 `t` 全部字符的最短子串。

## 最优思路

滑动窗口：右扩减少 `missing`，当覆盖完成后左缩更新最短。

## 图解

```mermaid
flowchart LR
  R[expand r] --> C{covered?}
  C -->|yes| L[shrink l + update best]
  L --> C
  C -->|no| R
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(|s|+|t|)\) |
| 空间 | \(O(\Sigma)\) |
