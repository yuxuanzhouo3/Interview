# LC 32. Longest Valid Parentheses

> Hard · [LeetCode](https://leetcode.com/problems/longest-valid-parentheses/)

## 题意

求最长合法括号子串长度。

## 最优思路

栈存下标，底为「最后一个未匹配 `)` 的位置」。遇 `)` 弹出；栈空则压入当前下标作新屏障，否则用 `i - st[-1]` 更新答案。

## 图解

```text
s: ) ( ) ( ) )
i: 0 1 2 3 4 5
最长:  ( ) ( )  → 4
```
