# LC 1392. Longest Happy Prefix

> Hard · [LeetCode](https://leetcode.com/problems/longest-happy-prefix/) · Tags: String, String Matching, Hash Function, Rolling Hash

## 题意

求既是真前缀又是真后缀的最长子串（happy prefix）。

## 最优思路

KMP 的 `lps` 数组末项即为最长 border 长度。
