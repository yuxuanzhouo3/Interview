# LC 1330. Reverse Subarray To Maximize Array Value

> Hard · [LeetCode](https://leetcode.com/problems/reverse-subarray-to-maximize-array-value/) · Tags: Array, Math, Greedy

## 题意

数组价值为相邻差绝对值之和；可反转恰好一个子数组，求最大价值。

## 最优思路

原和 + 增益。增益来自端点反转，或中间反转时 \(2(\max\min(a_i,a_{i+1})-\min\max(a_j,a_{j+1}))\)。

## 图解

```text
... a b ... c d ...
反转 [b..c] → |a-c|+|b-d| 替代 |a-b|+|c-d|
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(1)\) |
