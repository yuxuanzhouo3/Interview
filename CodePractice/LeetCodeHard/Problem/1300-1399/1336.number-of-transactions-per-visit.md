# LC 1336. Number of Transactions per Visit

> Hard · [LeetCode](https://leetcode.com/problems/number-of-transactions-per-visit/) · Premium · Tags: Database

## 题意

统计每次访问产生的交易笔数分布，从 0 到最大笔数连续输出。

## 最优思路

访问 LEFT JOIN 交易得次数；生成 0..max 序列再 LEFT JOIN 计数。

## 图解
