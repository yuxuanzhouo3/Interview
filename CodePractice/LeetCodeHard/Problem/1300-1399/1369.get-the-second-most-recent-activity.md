# LC 1369. Get the Second Most Recent Activity

> Hard · [LeetCode](https://leetcode.com/problems/get-the-second-most-recent-activity/) · Premium · Tags: Database

## 题意

每位用户取第二近的活动；若只有一次活动则返回该次。

## 最优思路

窗口 COUNT + RANK，过滤 rk=2 或仅一行。

## 图解

```text
SQL 窗口/聚合/透视 → 结果
```
