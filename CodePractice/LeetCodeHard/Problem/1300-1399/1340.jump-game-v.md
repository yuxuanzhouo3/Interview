# LC 1340. Jump Game V

> Hard · [LeetCode](https://leetcode.com/problems/jump-game-v/) · Tags: Array, Dynamic Programming

## 题意

从下标 `i` 最多跳 `d` 步到更矮的格子（中间不能有 ≥ 起点高度），求最多访问格数。

## 最优思路

记忆化 DFS：从 `i` 向左右延伸直到挡住，递归取最大链长。

## 图解

```text
… < arr[i] > …  within d, strictly decreasing path
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(nd)\) |
| 空间 | \(O(n)\) |
