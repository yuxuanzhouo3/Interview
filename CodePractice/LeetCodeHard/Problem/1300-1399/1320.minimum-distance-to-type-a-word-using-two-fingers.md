# LC 1320. Minimum Distance to Type a Word Using Two Fingers

> Hard · [LeetCode](https://leetcode.com/problems/minimum-distance-to-type-a-word-using-two-fingers/) · Tags: String, Dynamic Programming

## 题意

两指在 6×5 字母键盘上打字，曼哈顿距离；求打完 `word` 的最小移动距离（初始可任意放置，不计第一次落地）。

## 最优思路

DP：`dp[a][b]` 表示两指分别在字母 `a/b`（可「未放置」）时的最小代价；每键任选一指移动。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\cdot 26^2)\) |
| 空间 | \(O(26^2)\) |
