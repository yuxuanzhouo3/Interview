# LC 1373. Maximum Sum BST in Binary Tree

> Hard · [LeetCode](https://leetcode.com/problems/maximum-sum-bst-in-binary-tree/) · Tags: Tree, DFS, BST, DP on Trees

## 题意

求二叉树中任意子树是 BST 时的最大结点值和（若全负可为 0）。

## 最优思路

后序返回 `(是否BST, 子树min, 子树max, 子树和)`，合法则更新全局答案。

## 图解

```text
left.max < root < right.min → BST sum
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(h)\) |
