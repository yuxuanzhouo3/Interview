# LC 1345. Jump Game IV

> Hard · [LeetCode](https://leetcode.com/problems/jump-game-iv/) · Tags: Array, Hash Table, BFS

## 题意

可跳到相邻下标，或跳到同值任意下标，求到末尾最少步数。

## 最优思路

BFS；用值→下标列表做同值跳跃，用过即清空避免重复。

## 图解

```text
i ↔ i±1  or  same value indices
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
