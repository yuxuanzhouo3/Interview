# LC 1368. Minimum Cost to Make at Least One Valid Path in a Grid

> Hard · [LeetCode](https://leetcode.com/problems/minimum-cost-to-make-at-least-one-valid-path-in-a-grid/) · Tags: 0-1 BFS, Shortest Path

## 题意

格子箭头限定下一步方向；改箭头代价 1，求从左上到右下最小代价。

## 最优思路

边权仅 0/1 → **0-1 BFS**（双端队列）。

## 图解

```text
follow arrow cost 0 → front; change cost 1 → back
```
