# LC 1312. Minimum Insertion Steps to Make a String Palindrome

> Hard · [LeetCode](https://leetcode.com/problems/minimum-insertion-steps-to-make-a-string-palindrome/) · Tags: String, DP

## 题意

最少插入字符使 `s` 成为回文。

## 最优思路

答案 = `n - LCS(s, reverse(s))`（最长回文子序列长度）。

## 图解

```text
keep LPS, insert the rest mirrored
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2)\) |
| 空间 | \(O(n)\) |
