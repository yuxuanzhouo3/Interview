# LC 1397. Find All Good Strings

> Hard · [LeetCode](https://leetcode.com/problems/find-all-good-strings/) · Tags: String, DP, String Matching

## 题意

统计长度 `n`、字典序在 `[s1,s2]`、且不包含子串 `evil` 的小写串个数。

## 最优思路

数位 DP：位置 + KMP 匹配状态 + 上下界紧约束；转移用 KMP 自动机。

## 图解

```text
pos, kmp_state, tightL, tightR → 枚举下一位
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\cdot|evil|\cdot 26)\) |
| 空间 | \(O(n\cdot|evil|)\) |
