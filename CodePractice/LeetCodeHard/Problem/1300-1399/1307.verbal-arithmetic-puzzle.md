# LC 1307. Verbal Arithmetic Puzzle

> Hard · [LeetCode](https://leetcode.com/problems/verbal-arithmetic-puzzle/) · Tags: Backtracking, Math

## 题意

给单词加法式，判断是否存在字母到数字的双射使等式成立（前导零非法）。

## 最优思路

按列从低到高回溯，枚举未赋值字母；结果位校验进位。

## 图解

```text
  SEND
+ MORE
------
 MONEY   ← 逐列 + 进位
```
