# LC 1359. Count All Valid Pickup and Delivery Options

> Hard · [LeetCode](https://leetcode.com/problems/count-all-valid-pickup-and-delivery-options/) · Tags: Math, DP, Combinatorics

## 题意

`n` 单货物，每单先取后送，求合法排列数（mod \(10^9+7\)）。

## 最优思路

递推：已有 `2(i-1)` 个位置，插入第 `i` 单的 `P` 有 `2i-1` 个空位，`D` 只能在 `P` 之后 → 乘 `(2i-1)*i`。

## 图解

```text
ans *= (2i-1) * i
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(1)\) |
