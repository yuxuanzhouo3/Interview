# LC 903. Valid Permutations for DI Sequence

> Hard · [LeetCode](https://leetcode.com/problems/valid-permutations-for-di-sequence/) · Tags: String, Dynamic Programming, Prefix Sum

## 题意

给定只含 `D`/`I` 的串 `s`（长度 n），求排列 `P[0..n]` 使得相邻满足下降/上升的方案数（模 \(10^9+7\)）。

## 最优思路

DP：处理完前 `i` 个字符后，用相对秩表示当前位置可用数。遇 `I` 用前缀和转移，遇 `D` 用后缀和；\(O(n^2)\)。

## 图解

```mermaid
flowchart LR
  A[dp ranks] -->|I: prefix| B[ndp]
  A -->|D: suffix| B
  B --> C[下一字符]

```
