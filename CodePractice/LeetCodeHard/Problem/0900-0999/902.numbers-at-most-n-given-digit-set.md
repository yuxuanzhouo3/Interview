# LC 902. Numbers At Most N Given Digit Set

> Hard · [LeetCode](https://leetcode.com/problems/numbers-at-most-n-given-digit-set/) · Tags: Array, Math, String, Binary Search, Dynamic Programming

## 题意

给定数字字符集合 `digits`（不含前导零）与整数 `n`，问用这些数字能组成多少个 **≤ n** 的正整数（可重复用）。

## 最优思路

先统计位数更短的全部 \(m^L\)。对等长情况按位贪心/数位 DP：前缀已贴紧 `n` 时，当前位置选更小数字则后缀任意；若当前位不在集合则停止；若完整匹配 `n` 则再 +1。

## 图解

```mermaid
flowchart TD
  A[长度 < D] -->|m^L 求和| B[答案]
  C[长度 = D] --> D{逐位}
  D -->|选更小 digit| E[后缀自由 m^{剩}]
  D -->|贴紧| F[下一位]
  F --> G{完整匹配?}
  G -->|是| H[+1]

```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(D \\cdot |digits|)\) |
| 空间 | \(O(1)\) |
