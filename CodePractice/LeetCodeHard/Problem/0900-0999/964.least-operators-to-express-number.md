# LC 964. Least Operators to Express Number

> Hard · [LeetCode](https://leetcode.com/problems/least-operators-to-express-number/) · Tags: Math, DP, Memoization

## 题意

只用数字 \(x\) 与 `+ - * /`（整除），构造表达式等于 `target`，求最少运算符数。

## 最优思路

在 \(x\) 的幂次附近分解：取不超过 \(t\) 的最大 \(y=x^k\)，递归 \(t-y\)；或取下一幂 \(x^{k+1}-t\)（仅当余数更小）。小于 \(x\) 时比较「若干 \(x/x\)」与「从 \(x\) 减」。

## 图解

```text
t → y=x^k ≤ t
  → cost(y) + 1 + dfs(t-y)
  → or cost(x^{k+1}) + 1 + dfs(x^{k+1}-t)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(\log_x T)\) |
| 空间 | \(O(\log_x T)\) |
