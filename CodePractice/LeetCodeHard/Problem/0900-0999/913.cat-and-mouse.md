# LC 913. Cat and Mouse

> Hard · [LeetCode](https://leetcode.com/problems/cat-and-mouse/) · Tags: DP, Graph, Game Theory

## 题意

鼠从 1、猫从 2 出发，鼠先手。鼠到 0 获胜，猫鼠同格猫胜，否则可能平局。返回 1/2/0。

## 最优思路

状态 `(mouse, cat, turn)`。已知终态入队；若当前玩家能一步到己方必胜则染色，否则出度减至 0 时被迫接受结果（拓扑博弈 DP）。

## 图解

```text
mouse@0 → Mouse
mouse==cat → Cat
else propagate via parents
```

| 时间 | \(O(n^3)\) |
| 空间 | \(O(n^2)\) |
