# LC 943. Find the Shortest Superstring

> Hard · [LeetCode](https://leetcode.com/problems/find-the-shortest-superstring/) · Tags: Array, String, Dynamic Programming, Bit Manipulation, Bitmask, Hamiltonian Path

## 题意

给定若干互不相同的单词，求包含每个单词作为子串的最短超串。

## 最优思路

先算两两 overlap，再 TSP 状压 DP：`dp[mask][j]` 为覆盖 mask、以 j 结尾的最短串；转移拼接非重叠后缀。
