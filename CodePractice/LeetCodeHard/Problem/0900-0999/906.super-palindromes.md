# LC 906. Super Palindromes

> Hard · [LeetCode](https://leetcode.com/problems/super-palindromes/) · Tags: Math, String, Enumeration

## 题意

统计 \([left,right]\) 内「超回文」个数：自身是回文且平方根也是整数回文。

## 最优思路

根 \(\le 10^9\)，枚举回文根（奇/偶长，前缀 \(\le 10^5\)），平方后检查是否回文且落在区间。

## 图解

```text
prefix k → palindrome p → p²
count if L ≤ p² ≤ R and p² palindrome
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(W^{1/4})\) |
| 空间 | \(O(1)\) |
