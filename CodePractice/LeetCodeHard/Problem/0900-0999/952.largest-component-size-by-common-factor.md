# LC 952. Largest Component Size by Common Factor

> Hard · [LeetCode](https://leetcode.com/problems/largest-component-size-by-common-factor/) · Tags: Array, Hash Table, Math, Union-Find, Number Theory, Prime Factorization

## 题意

数组中两数若有公共因子 >1 则可连边；求最大连通分量大小。

## 最优思路

对每个数与其质因子做并查集连通，再统计每个根上有多少数组元素。

## 图解

```mermaid
flowchart TD
  A[nums] --> B[质因数分解]
  B --> C[union(num, factor)]
  C --> D[按根计数最大值]

```
