# LC 2398. Maximum Number of Robots Within Budget

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-robots-within-budget/) · Tags: Array, Sliding Window, Monotonic Queue

## 题意

选连续 `k` 个机器人，代价 = `max(charge) + k * sum(running)`；求预算内最大 `k`。

## 最优思路

滑动窗口 + 单调队列维护区间最大 charge；超预算缩左端。

## 图解

```text
cost = max(charge[i..j]) + (j-i+1) * sum(run[i..j])
```
