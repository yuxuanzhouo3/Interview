# LC 2386. Find the K-Sum of an Array

> Hard · [LeetCode](https://leetcode.com/problems/find-the-k-sum-of-an-array/) · Tags: Array, Sorting, Heap (Priority Queue)

## 题意

数组所有子序列和中第 `k` 大的和（空子序列和为 0）。

## 最优思路

最大和 = 所有正数之和。用最小绝对值序列在堆上做「第 k 小扣减」，等价枚举下一候选子序列和。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log n + k\log k)\) |
| 空间 | \(O(n+k)\) |
