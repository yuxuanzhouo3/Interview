# LC 2307. Check for Contradictions in Equations

> Hard · [LeetCode](https://leetcode.com/problems/check-for-contradictions-in-equations/) · Tags: Array, String, Depth-First Search, Union-Find, Graph Theory

## 题意

给定形如 `a / b = v` 的等式，判断是否存在矛盾（相对误差 `1e-5`）。

## 最优思路

带权并查集：维护 `weight[x] = x / parent(x)`；同根时校验 `weight[a]/weight[b]` 是否等于 `v`，否则按比值合并。

## 图解

```text
a --v--> b   ⇒  path products must agree
```

## 复杂度

| 时间 | \(O(n\alpha(n))\) |
| 空间 | \(O(n)\) |
