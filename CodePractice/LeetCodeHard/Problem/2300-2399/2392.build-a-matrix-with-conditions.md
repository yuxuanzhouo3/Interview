# LC 2392. Build a Matrix With Conditions

> Hard · [LeetCode](https://leetcode.com/problems/build-a-matrix-with-conditions/) · Tags: Graph, Topological Sort, Matrix

## 题意

把 `1..k` 填入 `k×k` 矩阵（每数一次）；`rowConditions`/`columnConditions` 表示先后相对位置；无解返回 `[]`。

## 最优思路

行、列条件各自拓扑排序得行号/列号；有环则无解；把数字放在 `(row[x], col[x])`。

## 图解

```text
row topo → 垂直顺序
col topo → 水平顺序
matrix[r][c] = x
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(k^2 + e)\) |
| 空间 | \(O(k^2 + e)\) |
