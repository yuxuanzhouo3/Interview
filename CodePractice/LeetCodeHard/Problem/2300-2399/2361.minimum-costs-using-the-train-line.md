# LC 2361. Minimum Costs Using the Train Line

> Hard · [LeetCode](https://leetcode.com/problems/minimum-costs-using-the-train-line/) · Tags: Array, Dynamic Programming

## 题意

普通/快线并行，转快线付 expressCost，求到各站最小费用。

## 最优思路

滚动 DP：`f` 到站走普通，`g` 走快线。

## 图解

```text
reg <---> exp (pay expressCost when entering exp)
```

| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
