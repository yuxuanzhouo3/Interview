# LC 2360. Longest Cycle in a Graph

> Hard · [LeetCode](https://leetcode.com/problems/longest-cycle-in-a-graph/) · Tags: Graph, DFS

## 题意

有向图每个节点出度 ≤1；求最长环长度，无环返回 -1。

## 最优思路

按路径打时间戳；若再次走到「本趟」访问过的点，则环长 = `clock - time[u]`。

## 图解

```text
path: a→b→c→d→b  ; cycle len = time_now - time[b]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
