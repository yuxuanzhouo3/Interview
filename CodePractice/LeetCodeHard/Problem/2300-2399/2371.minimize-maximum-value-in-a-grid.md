# LC 2371. Minimize Maximum Value in a Grid

> Hard · [LeetCode](https://leetcode.com/problems/minimize-maximum-value-in-a-grid/) · Tags: Array, Union-Find, Graph Theory, Topological Sort, Sorting, Matrix

## 题意

把网格改成正整数，保持严格相对大小（同行/同列比较），最小化最大值。

## 最优思路

按原值排序填入：每格取 `max(行已用, 列已用)+1`。

## 图解

```text
sort cells by value → assign max(row,col)+1
```

## 复杂度

| 时间 | \(O(mn\log(mn))\) |
| 空间 | \(O(mn)\) |
