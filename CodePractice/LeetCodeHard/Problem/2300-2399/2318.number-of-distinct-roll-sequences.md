# LC 2318. Number of Distinct Roll Sequences

> Hard · [LeetCode](https://leetcode.com/problems/number-of-distinct-roll-sequences/) · Tags: Dynamic Programming, Memoization

## 题意

掷骰子长度 `n`：相邻面互质，且长度 3 窗口内无面不重复。求序列数 mod \(10^9+7\)。

## 最优思路

`dp[a][b]`：最后两面为 `a,b` 的方案数；扩展 `c` 时要求 `gcd(b,c)=1` 且 `c≠a,c≠b`。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(1)\) |
