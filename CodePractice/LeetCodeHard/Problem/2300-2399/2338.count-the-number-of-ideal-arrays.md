# LC 2338. Count the Number of Ideal Arrays

> Hard · [LeetCode](https://leetcode.com/problems/count-the-number-of-ideal-arrays/) · Tags: Math, Dynamic Programming, Combinatorics, Number Theory, Prime Factorization, Fermat's Little Theorem

## 题意

长度为 `n`、元素在 `[1,maxValue]` 的数组，满足后项整除前项（`a[i]` 整除 `a[i+1]`），求个数 mod \(10^9+7\)。

## 最优思路

对每个结尾值质因数分解；每个指数 `e` 在长度 `n` 的非降链上相当于星星棒 `C(n-1+e,e)`，各素数独立相乘后对结尾求和。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(\mathrm{maxValue}\log + n)\) |
| 空间 | \(O(\mathrm{maxValue}+n)\) |
