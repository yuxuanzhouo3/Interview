# LC 2355. Maximum Number of Books You Can Take

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-books-you-can-take/) · Tags: Array, Dynamic Programming, Stack, Monotonic Stack

## 题意

从连续书架取书，相邻严格递增（向右），求最多取书数。

## 最优思路

单调栈找左瓶颈 j；`dp[i]=等差段和+dp[j]`。

## 图解

```text
... j | (arith -> books[i])
```

## 复杂度

| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
