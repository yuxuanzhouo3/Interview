# LC 2366. Minimum Replacements to Sort the Array

> Hard · [LeetCode](https://leetcode.com/problems/minimum-replacements-to-sort-the-array/) · Tags: Array, Math, Greedy

## 题意

把一个数拆成若干正整数之和替换它；求使数组非递减的最少拆分次数。

## 最优思路

从右往左：当前值 `x` 若 `> prev`，拆成 `k=⌈x/prev⌉` 段，代价 `k-1`，新的 `prev` 取最左段 `x//k`。

## 图解

```text
… x | prev
x > prev → split into k parts ≤ prev, leftmost as new prev
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(1)\) |
