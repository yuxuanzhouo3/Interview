# LC 329. Longest Increasing Path in a Matrix

> Hard · [LeetCode](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/)

## 题意

矩阵中最长严格递增路径长度。

## 最优思路

记忆化 DFS：向四方向走更大格子，`dp[i][j]=1+max(邻居)`。

## 图解

```text
9→6→2→1 length? better 1→2→6→9 = 4
```
