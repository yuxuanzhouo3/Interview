# LC 321. Create Maximum Number

> Hard · [LeetCode](https://leetcode.com/problems/create-maximum-number/)

## 题意

从两数组共取 k 个数保持相对顺序，组成最大数。

## 最优思路

枚举从 nums1 取 i 个；单调栈取子序列；两序列按字典序合并取较大。

## 图解

```text
pick(i) + pick(k-i) → merge like merge-sort but max lexicographic
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(k(n+m)^2)\) 量级 |
| 空间 | \(O(k)\) |
