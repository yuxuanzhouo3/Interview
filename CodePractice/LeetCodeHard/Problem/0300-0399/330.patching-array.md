# LC 330. Patching Array

> Hard · [LeetCode](https://leetcode.com/problems/patching-array/)

## 题意

最少补多少个数，使 `[1,n]` 都能被子集和表示。

## 最优思路

维护已覆盖 `[1,miss)`；能用 `nums[i]` 则扩展，否则补 `miss` 本身使覆盖翻倍。

## 图解

```text
cover [1,miss) ; add nums[i] if <=miss else patch miss
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(m+\log n)\) |
| 空间 | \(O(1)\) |
