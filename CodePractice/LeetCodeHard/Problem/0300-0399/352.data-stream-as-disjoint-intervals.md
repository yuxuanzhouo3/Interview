# LC 352. Data Stream as Disjoint Intervals

> Hard · [LeetCode](https://leetcode.com/problems/data-stream-as-disjoint-intervals/)

## 题意

数据流插入整数，随时输出合并后的不相交区间。

## 最优思路

有序区间列表；插入后与相邻区间若 `|a-b|<=1` 则合并。

## 图解

```text
1,3,7,2,6 → [1,3],[6,7]
```

## 复杂度

| 项 | 值 |
|----|----|
| add | \(O(k)\) |
| get | \(O(k)\) |
