# LC 336. Palindrome Pairs

> Hard · [LeetCode](https://leetcode.com/problems/palindrome-pairs/)

## 题意

找所有下标对 `(i,j)` 使 `words[i]+words[j]` 为回文。

## 最优思路

哈希词→下标；枚举切分，一侧已回文则查另一侧反串是否存在。

## 图解

```text
word = left|right ; if left pal → need rev(right) as partner before
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n L^2)\) |
| 空间 | \(O(n L)\) |
