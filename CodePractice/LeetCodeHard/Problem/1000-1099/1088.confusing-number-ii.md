# LC 1088. Confusing Number II

> Hard · [LeetCode](https://leetcode.com/problems/confusing-number-ii/) · Premium · Tags: Math, Backtracking

## 题意

统计 ≤ n 的易混淆数：仅含 0/1/6/8/9，旋转 180° 后仍有效且数值不同。

## 最优思路

回溯只生成合法数字，再判断旋转后是否变化。

## 图解

```text
Input → 只生成可旋转数字并检查翻转后不同 → Answer
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(5^{log n}) |
| 空间 | O(log n) |
