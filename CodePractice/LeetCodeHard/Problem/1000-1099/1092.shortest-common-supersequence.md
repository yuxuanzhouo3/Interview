# LC 1092. Shortest Common Supersequence

> Hard · [LeetCode](https://leetcode.com/problems/shortest-common-supersequence/) · Tags: String, DP, LCS

## 题意

求最短公共超序列：同时以 `str1`、`str2` 为子序列的最短串。

## 最优思路

先求 LCS DP；从右下回溯：相等取公共字符，否则沿较大方向取单侧字符，最后补前缀。

## 图解

```text
SCS length = m + n - LCS
reconstruct from dp table
```
