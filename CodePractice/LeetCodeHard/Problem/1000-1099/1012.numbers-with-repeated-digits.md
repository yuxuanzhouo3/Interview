# LC 1012. Numbers With Repeated Digits

> Hard · [LeetCode](https://leetcode.com/problems/numbers-with-repeated-digits/) · Tags: Math, Dynamic Programming

## 题意

统计 \(1..n\) 中至少有一位数字重复的正整数个数。

## 最优思路

等价于 \(n - \)（各位数字互不相同的个数）。按位数排列数 + 同长度前缀约束枚举。

## 图解

```text
unique = shorter lens + same-len prefix walk
answer = n - unique
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(\log n)\) |
| 空间 | \(O(\log n)\) |
