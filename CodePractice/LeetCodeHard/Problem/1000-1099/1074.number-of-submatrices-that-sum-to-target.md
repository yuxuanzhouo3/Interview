# LC 1074. Number of Submatrices That Sum to Target

> Hard · [LeetCode](https://leetcode.com/problems/number-of-submatrices-that-sum-to-target/) · Tags: Array, Hash Table, Matrix, Prefix Sum

## 题意

统计子矩阵和等于 `target` 的个数。

## 最优思路

枚举左右列，压缩成行前缀；一维「和为 target 的子数组」用哈希计数。

## 图解

```text
for L..R:
  row_sum[i] += mat[i][R]
  1D prefix-hash count target
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(m^2 n)\) 或 \(O(n^2 m)\) |
| 空间 | \(O(m)\) |
