# LC 1067. Digit Count in Range

> Hard · [LeetCode](https://leetcode.com/problems/digit-count-in-range/) · Premium · Tags: Math, Digit DP

## 题意

统计闭区间 [low, high] 内数字 d 出现的总次数。

## 最优思路

数位 DP：count(high)-count(low-1)；注意前导零不计入 digit 0。

## 图解

```text
Input → 数位 DP 统计 digit 出现次数 → Answer
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(log high) |
| 空间 | O(log high) |
