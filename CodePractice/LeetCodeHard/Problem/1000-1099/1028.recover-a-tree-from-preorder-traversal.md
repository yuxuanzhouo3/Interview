# LC 1028. Recover a Tree From Preorder Traversal

> Hard · [LeetCode](https://leetcode.com/problems/recover-a-tree-from-preorder-traversal/) · Tags: String, Tree, DFS, Binary Tree

## 题意

由先序遍历字符串（`-` 个数表示深度）还原二叉树。

## 最优思路

扫描解析 (depth, val)；栈维护当前路径，弹出到父深度后挂左/右孩子。

## 图解

```text
1-2--3--4-5--6--7
stack depths: 0→1→2 …
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(h)\) |
