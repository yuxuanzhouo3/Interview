# LC 1097. Game Play Analysis V

> Hard · [LeetCode](https://leetcode.com/problems/game-play-analysis-v/) · Premium · Tags: Database

## 题意

按安装日统计安装人数与次日留存率。

## 最优思路

子查询取每人首登日；LEFT JOIN 次日活动；按安装日算留存比例。
