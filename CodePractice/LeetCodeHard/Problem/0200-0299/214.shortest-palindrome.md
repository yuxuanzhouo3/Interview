# LC 214. Shortest Palindrome

> Hard · [LeetCode](https://leetcode.com/problems/shortest-palindrome/)

## 题意

在字符串前加最少字符，使其成为回文。

## 最优思路

KMP：对 `s + '#' + reverse(s)` 求 LPS；末值 = `s` 前缀已是回文的最长长度，前面补剩余反转。

## 图解

```text
s=aacecaaa  → lps end covers "aacecaa" → add "a"
```
