# LC 295. Find Median from Data Stream

> Hard · [LeetCode](https://leetcode.com/problems/find-median-from-data-stream/)

## 题意

动态数据流求中位数。

## 最优思路

大根堆存左半、小根堆存右半；保持 `size(lo) == size(hi)` 或 `lo` 多 1。

## 图解

```mermaid
flowchart LR
  X[num] --> LO[max-heap left]
  LO --> HI[min-heap right]
  HI --> Balance[rebalance sizes]
```

## 复杂度

| 项 | 值 |
|----|----|
| add | \(O(\log n)\) |
| median | \(O(1)\) |
