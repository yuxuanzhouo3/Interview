# LC 220. Contains Duplicate III

> Hard · [LeetCode](https://leetcode.com/problems/contains-duplicate-iii/)

## 题意

是否存在 `|i-j|≤indexDiff` 且 `|nums[i]-nums[j]|≤valueDiff`。

## 最优思路

按桶宽 `valueDiff+1` 分桶；同桶必命中；检查相邻桶；维护窗口大小 `indexDiff`。

## 图解

```text
buckets of width t+1 → same or neighbor bucket check
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(\min(n,k))\) |
