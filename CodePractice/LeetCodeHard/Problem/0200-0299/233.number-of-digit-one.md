# LC 233. Number of Digit One

> Hard · [LeetCode](https://leetcode.com/problems/number-of-digit-one/)

## 题意

统计 1..n 十进制表示中数字 `1` 出现次数。

## 最优思路

按位权统计：拆 `high/cur/low`，分 `cur==0/1/>1` 三种贡献。

## 图解

```text
n=13 → ones at: 1,10,11,12,13 → 6
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(\log n)\) |
| 空间 | \(O(1)\) |
