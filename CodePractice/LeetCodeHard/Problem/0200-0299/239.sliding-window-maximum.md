# LC 239. Sliding Window Maximum

> Hard · [LeetCode](https://leetcode.com/problems/sliding-window-maximum/)

## 题意

大小为 k 的滑动窗口最大值序列。

## 最优思路

单调递减双端队列存下标；队头为窗口最大，过期弹出。

## 图解

```mermaid
flowchart LR
  In[new x] --> PopBack[pop ≤ x]
  PopBack --> Push
  Push --> PopFront[pop out of window]
  PopFront --> Ans[front = max]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(k)\) |
