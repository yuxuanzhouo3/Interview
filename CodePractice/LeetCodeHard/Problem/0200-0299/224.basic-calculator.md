# LC 224. Basic Calculator

> Hard · [LeetCode](https://leetcode.com/problems/basic-calculator/)

## 题意

计算含 `+ - ( )` 与空格的表达式。

## 最优思路

遇 `(` 压入当前结果与符号并重置；遇 `)` 弹出合并。

## 图解

```text
(1+(4+5+2)-3)+(6+8)
 stack saves context at each '('
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
