# LC 1916. Count Ways to Build Rooms in an Ant Colony

> Hard · [LeetCode](https://leetcode.com/problems/count-ways-to-build-rooms-in-an-ant-colony/) · Tags: Array, Math, Dynamic Programming, Tree, Depth-First Search, Graph Theory, Topological Sort, Combinatorics, DP on Trees, Fermat's Little Theorem

## 题意

建房：房间 \(i\) 必须在 `prevRoom[i]` 之后建。求拓扑序方案数（模 \(10^9+7\)）。

## 最优思路

树形 DP：子树大小为 \(s_1,\dots,s_k\) 时，合并方案为多项系数 \(\frac{(s_1+\cdots+s_k)!}{s_1!\cdots s_k!}\)，逐对用 `comb` 累乘。

## 图解

```text
  0
 / \
1   2
子树交错：C(sz1+sz2, sz1) 种
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\)（comb 可预计算） |
| 空间 | \(O(n)\) |
