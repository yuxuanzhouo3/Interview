# LC 1948. Delete Duplicate Folders in System

> Hard · [LeetCode](https://leetcode.com/problems/delete-duplicate-folders-in-system/) · Tags: Array, Hash Table, String, Depth-First Search, Trie, Sorting, Hash Function

## 题意

文件夹路径列表，若两子树结构（文件夹名序列）完全相同则整棵子树删除。返回剩余路径。

## 最优思路

建 Trie，序列化每个结点的子树结构；相同序列标记删除；再 DFS 收集未删路径。

## 图解

```text
a/b 与 c/b 结构相同 → 删 a 与 c 整棵
留下 d, d/a
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(N\log N)\)（排序序列化） |
| 空间 | \(O(N)\) |
