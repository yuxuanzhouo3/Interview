# LC 1932. Merge BSTs to Create Single BST

> Hard · [LeetCode](https://leetcode.com/problems/merge-bsts-to-create-single-bst/) · Tags: Array, Hash Table, Tree, Depth-First Search, Binary Search Tree, Binary Tree

## 题意

若干至多 3 结点的 BST，可把某树根接到另一树同值叶子上。做 \(n-1\) 次后若得合法 BST 则返回根，否则 null。

## 最优思路

叶子值与根值唯一对应，挂接方式唯一。最终根值不出现在任何叶子。按映射拼接后中序检查严格递增且合并次数正确。

## 图解

```text
叶=根值 → 用那棵树替换叶
唯一未作叶的根 = 整棵树根
```
