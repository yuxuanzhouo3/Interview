# LC 1919. Leetcodify Similar Friends

> Hard · [LeetCode](https://leetcode.com/problems/leetcodify-similar-friends/) · Premium · Tags: Database

## 题意

找出好友中存在某天共同听 ≥3 首歌的用户对。

## 最优思路

Friendship ⋈ Listens×2，按日 HAVING COUNT DISTINCT ≥3。

## 图解

```text
friends ∧ same-day songs≥3
```
