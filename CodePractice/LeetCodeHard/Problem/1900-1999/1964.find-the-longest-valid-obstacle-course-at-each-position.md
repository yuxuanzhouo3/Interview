# LC 1964. Find the Longest Valid Obstacle Course at Each Position

> Hard · [LeetCode](https://leetcode.com/problems/find-the-longest-valid-obstacle-course-at-each-position/) · Tags: Array, Binary Search, BIT

## 题意

对每个下标 `i`，求以 `obstacles[i]` 结尾的最长**非严格递增**子序列长度。

## 最优思路

经典 LIS tails：`bisect_right` 允许相等，位置 `j+1` 即为答案。

## 图解

```text
tails[j] = 长 j+1 的非降子序列最小结尾
bisect_right → 可接在等长或更短后
```

## 复杂度

| 时间 | \(O(n\log n)\) |
| 空间 | \(O(n)\) |
