# LC 1917. Leetcodify Friends Recommendations

> Hard · [LeetCode](https://leetcode.com/problems/leetcodify-friends-recommendations/) · Premium · Tags: Database

## 题意

同日共同听 ≥3 首歌且非好友的用户互相推荐。

## 最优思路

自连接 Listens 按日计数，排除 Friendship，双向输出。

## 图解

```text
same day ∩ songs ≥ 3 ∧ ¬friends → recommend
```
