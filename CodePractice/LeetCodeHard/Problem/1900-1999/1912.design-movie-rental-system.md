# LC 1912. Design Movie Rental System

> Hard · [LeetCode](https://leetcode.com/problems/design-movie-rental-system/) · Tags: Design, Hash Table, Ordered Set

## 题意

设计租赁系统：`search` 未租某片最便宜 5 店；`rent`/`drop`；`report` 已租最便宜 5 条。

## 最优思路

未租：每电影有序集 `(price, shop)`；已租：全局 `(price, shop, movie)`；哈希存价。

## 图解

```mermaid
flowchart LR
  search --> U[unrented[:5]]
  rent --> M[移入 rented]
  drop --> B[移回 unrented]
```

## 复杂度

| 项 | 值 |
|----|----|
| 操作 | \(O(\log n)\)（有序集）/ \(O(n)\)（list 回退） |
| 空间 | \(O(n)\) |
