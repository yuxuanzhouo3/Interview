# LC 1977. Number of Ways to Separate Numbers

> Hard · [LeetCode](https://leetcode.com/problems/number-of-ways-to-separate-numbers/) · Tags: String, DP

## 题意

把数字串切成无前导零且非降的整数序列，求方案数。

## 最优思路

dp[i][j]：前 i 位、末段长 j；短末段必更小，等长用 LCP 比较。

## 图解

```text
num[:i] = ... | last(j)
```

| 时间 | O(n²) |
| 空间 | O(n²) |
