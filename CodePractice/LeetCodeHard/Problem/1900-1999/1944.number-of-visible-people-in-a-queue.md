# LC 1944. Number of Visible People in a Queue

> Hard · [LeetCode](https://leetcode.com/problems/number-of-visible-people-in-a-queue/) · Tags: Array, Stack, Monotonic Stack

## 题意

队列面向右；`i` 能看见 `j`（`i<j`）当且仅当中间所有人严格矮于 `min(h[i],h[j])`。对每人统计能看见多少人。

## 最优思路

从右往左维护严格递减单调栈：弹出所有更矮者（都能看见），若栈非空再 +1（看见第一个 ≥ 自己的人）。
