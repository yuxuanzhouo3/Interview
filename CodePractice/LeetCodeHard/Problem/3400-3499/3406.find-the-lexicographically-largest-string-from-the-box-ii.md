# LC 3406. Find the Lexicographically Largest String From the Box II

> Hard · [LeetCode](https://leetcode.com/problems/find-the-lexicographically-largest-string-from-the-box-ii/) · Tags: Two Pointers, String

## 题意

把字符串切成 `numFriends` 段，所有可能片段中字典序最大者；\(n\le 2\times 10^5\)。

## 最优思路

答案是「字典序最大后缀」的前 \(n-numFriends+1\) 个字符；用双指针求 last substring。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(1)\) |
