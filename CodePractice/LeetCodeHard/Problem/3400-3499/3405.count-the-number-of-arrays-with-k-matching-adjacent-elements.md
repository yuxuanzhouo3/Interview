# LC 3405. Count the Number of Arrays with K Matching Adjacent Elements

> Hard · [LeetCode](https://leetcode.com/problems/count-the-number-of-arrays-with-k-matching-adjacent-elements/) · Tags: Math, Combinatorics

## 题意

长度为 n、值域 [1,m]、恰有 k 处相邻相等的数组个数。

## 最优思路

`C(n-1,k) * m * (m-1)^{n-1-k}`：选 k 个相等邻接，其余必须变值。

## 图解

```text
C(n-1,k) * m * (m-1)^{n-1-k}
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(k + \\log MOD)$ |
| 空间 | $O(1)$ |
