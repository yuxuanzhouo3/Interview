# LC 3448. Count Substrings Divisible By Last Digit

> Hard · [LeetCode](https://leetcode.com/problems/count-substrings-divisible-by-last-digit/) · Tags: String, Dynamic Programming

## 题意

统计子串数值能被其最后一位数字整除的个数（末位不为 0）。

## 最优思路

对模 1..9 维护「以当前位置结尾的子串余数」计数，读入末位 d 时取 `cnt[d][0]`。

## 图解

```text
cnt[m][r] → extend *10+d
ans += cnt[d][0]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n \\cdot 81)$ |
| 空间 | $O(1)$ |
