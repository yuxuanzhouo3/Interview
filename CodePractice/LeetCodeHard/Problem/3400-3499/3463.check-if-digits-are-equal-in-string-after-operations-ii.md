# LC 3463. Check If Digits Are Equal in String After Operations II

> Hard · [LeetCode](https://leetcode.com/problems/check-if-digits-are-equal-in-string-after-operations-ii/) · Tags: Math, Combinatorics, Number Theory

## 题意

反复把相邻位 `(a+b)%10` 直到剩两位，判断是否相等。

## 最优思路

两位分别是二项式加权和；用 Lucas 在模 2、5 下比较再 CRT 到模 10。

## 图解

```text
left=Σ C(n-2,i)s[i]
check left≡right (mod 2 and 5)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n)$ |
| 空间 | $O(1)$ |
