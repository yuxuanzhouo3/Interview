# LC 3495. Minimum Operations to Make Array Elements Zero

> Hard · [LeetCode](https://leetcode.com/problems/minimum-operations-to-make-array-elements-zero/) · Tags: Array, Math, Bit Manipulation

## 题意

每次选最多两个正数各替换为 `floor(x/4)`；对每个询问区间 `[l,r]` 求变全 0 的最少操作，再求和。

## 最优思路

单个数需要 `floor(log4 x)+1` 次；区间求和后因每次可处理两个，答案为 `ceil(sum/2)`。

## 图解

```text
steps = floor(log4 x)+1
ans += ceil(Σ steps / 2)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(q \\log R)$ |
| 空间 | $O(1)$ |
