# LC 3695. Maximize Alternating Sum Using Swaps

> Hard · [LeetCode](https://leetcode.com/problems/maximize-alternating-sum-using-swaps/) · Tags: Array, Greedy, Union-Find

## 题意

交替和 `a0-a1+a2-a3+...`；可按 swaps 传递交换。求最大交替和。

## 最优思路

并查集连通分量内值可任意重排；大值优先放偶下标。

## 图解

```text
UF components; sort desc
largest → even indices
```

## 复杂度

| 时间 | $O(n\\log n)$ |
| 空间 | $O(n)$ |
