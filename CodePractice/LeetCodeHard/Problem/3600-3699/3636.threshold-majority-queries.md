# LC 3636. Threshold Majority Queries

> Hard · [LeetCode](https://leetcode.com/problems/threshold-majority-queries/) · Tags: Array, Hash Table, Binary Search, Divide and Conquer, Counting, Prefix Sum

## 题意

给你一个长度为 n 的整数数组 nums 和一个查询数组 queries，其中 queries[i] = [li, ri, thresholdi]。 返回一个整数数组 ans，其中 ans[i] 等于子数组 nums[li...ri] 中出现 至少 thresholdi 次的元素，选择频率 最高 的元素（如果频率相同则选择 最小 的元素），如果不存在这样的元…

## 最优思路

每次询问区间内出现次数不少于 $\textit{threshold}$ 的众数（并列取较大值）。 $n\le 10^4$、 $q\le 5\times 10^4$，暴力计数偏紧。 值域离散化后，可用莫队按左右端点分块，在移动窗口时维护频次数组与「达到阈值的候选」。阈值随询问变化，需按阈值再分桶或在块内回滚。 另一种实现是对每个询问在值域上二分「出现次数」，用主席树查区间第 $k$ 大的频率；但莫队更贴近阈值比较。移动指针时增减频次并更新答案。
