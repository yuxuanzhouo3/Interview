# LC 3686. Number of Stable Subsequences

> Hard · [LeetCode](https://leetcode.com/problems/number-of-stable-subsequences/) · Tags: Array, Dynamic Programming

## 题意

稳定子序列：奇偶性不会连续出现三次相同。求非空稳定子序列个数。

## 最优思路

DP 维护以 1/2 个奇数或偶数结尾的方案数，转移时避免变成 3。

## 图解

```text
dp[parity][run1/2]
append same → run+1 if <3
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(n)$ |
| 空间 | $O(1)$ |
