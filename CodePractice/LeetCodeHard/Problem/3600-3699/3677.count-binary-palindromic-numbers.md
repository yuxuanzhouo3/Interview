# LC 3677. Count Binary Palindromic Numbers

> Hard · [LeetCode](https://leetcode.com/problems/count-binary-palindromic-numbers/) · Tags: Math, Bit Manipulation

## 题意

统计 `[0,n]` 中二进制表示为回文的整数个数。

## 最优思路

按二进制长度枚举左半部分生成回文，计数 ≤ n 的。

## 图解

```text
enumerate half → mirror to palindrome
count ≤ n
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | $O(\\sqrt n)$ roughly / $O(2^{L/2})$ |
| 空间 | $O(1)$ |
