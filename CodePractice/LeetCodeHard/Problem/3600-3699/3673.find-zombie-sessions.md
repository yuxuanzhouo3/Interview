# LC 3673. Find Zombie Sessions

> Hard · [LeetCode](https://leetcode.com/problems/find-zombie-sessions/) · Tags: 

## 题意

表：app_events +------------------+----------+ | Column Name | Type | +------------------+----------+ | event_id | int | | user_id | int | | event_timestamp | datetime | | event_type…

## 最优思路

僵尸会话由时长、滚动次数、点击滚动比与是否购买共同刻画，按 $(\textit{session\_id},\textit{user\_id})$ 聚合即可。 时长取时间戳最大最小之差的分钟数；三类事件分别计数。 保留时长不少于 $30$、滚动不少于 $5$、点击比小于 $0.2$ 且无购买的会话，按滚动数降序、会话号升序输出。
