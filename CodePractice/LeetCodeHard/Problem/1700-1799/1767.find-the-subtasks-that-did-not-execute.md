# LC 1767. Find the Subtasks That Did Not Execute

> Hard · [LeetCode](https://leetcode.com/problems/find-the-subtasks-that-did-not-execute/) · Premium · Tags: Database

## 题意

找出每个任务未执行的子任务编号。

## 最优思路

递归 CTE 展开 1..subtasks_count，LEFT JOIN Executed 取空。
