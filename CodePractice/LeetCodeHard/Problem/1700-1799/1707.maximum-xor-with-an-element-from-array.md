# LC 1707. Maximum XOR With an Element From Array

> Hard · [LeetCode](https://leetcode.com/problems/maximum-xor-with-an-element-from-array/) · Tags: Trie, Bit Manipulation

## 题意

对每个查询 `(x,m)`，在 `≤m` 的数组元素中找与 `x` 异或最大者；无则 -1。

## 最优思路

查询按 `m` 排序离线插入二进制 Trie，贪心走相反位。

## 图解

```text
nums↑ 插入 Trie ← queries by m
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O((n+q)\log A)\) |
| 空间 | \(O(n\log A)\) |
