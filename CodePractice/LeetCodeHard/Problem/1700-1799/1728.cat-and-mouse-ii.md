# LC 1728. Cat and Mouse II

> Hard · [LeetCode](https://leetcode.com/problems/cat-and-mouse-ii/) · Tags: Game Theory, DP, BFS

## 题意

网格上鼠猫轮流跳（有跳限），鼠先手；鼠到食物获胜，猫到食物或同格则鼠败。判断鼠是否必胜。

## 最优思路

记忆化博弈：`dfs(鼠位,猫位,回合)`；回合超界视为平局（鼠负）。

## 图解

```text
鼠尽量找 True 分支；猫尽量堵成 False
```
