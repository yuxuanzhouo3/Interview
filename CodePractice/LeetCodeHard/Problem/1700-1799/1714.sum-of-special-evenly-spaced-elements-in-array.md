# LC 1714. Sum Of Special Evenly-Spaced Elements In Array

> Hard · [LeetCode](https://leetcode.com/problems/sum-of-special-evenly-spaced-elements-in-array/) · Premium · Tags: Array, Sqrt Decomposition

## 题意

查询从 x 起步长 y 的元素和（mod 1e9+7）。

## 最优思路

y≤√n 用预处理后缀和；否则直接扫。

## 图解

```text
suf[y][x] = nums[x] + nums[x+y] + ...
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O((n+q)√n) |
| 空间 | O(n√n) |
