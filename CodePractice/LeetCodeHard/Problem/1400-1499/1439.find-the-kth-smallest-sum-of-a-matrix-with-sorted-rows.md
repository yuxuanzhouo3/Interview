# LC 1439. Find the Kth Smallest Sum of a Matrix With Sorted Rows

> Hard · [LeetCode](https://leetcode.com/problems/find-the-kth-smallest-sum-of-a-matrix-with-sorted-rows/) · Tags: Heap, Matrix

## 题意

每行取一个数求和，求第 `k` 小的和。

## 最优思路

逐行把「当前候选和小数组」与下一行做堆合并，只保留前 `k` 个和。

## 图解

```text
sums ⨝ row → keep k smallest
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(mk\log k)\) |
| 空间 | \(O(k)\) |
