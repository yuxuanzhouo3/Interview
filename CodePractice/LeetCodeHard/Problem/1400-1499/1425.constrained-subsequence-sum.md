# LC 1425. Constrained Subsequence Sum

> Hard · [LeetCode](https://leetcode.com/problems/constrained-subsequence-sum/) · Tags: DP, Monotonic Queue

## 题意

非空子序列且相邻选取下标差 ≤ `k`，求最大元素和。

## 最优思路

`dp[i]=nums[i]+max(0, max(dp[i-k..i-1]))`，单调队列维护窗口最大值。

## 图解

```text
window [i-k, i) → max dp → dp[i]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
