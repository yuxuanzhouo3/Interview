# LC 1420. Build Array Where You Can Find The Maximum Exactly K Comparisons

> Hard · [LeetCode](https://leetcode.com/problems/build-array-where-you-can-find-the-maximum-exactly-k-comparisons/) · Tags: DP, Prefix Sum

## 题意

构造长度 `n`、元素 ∈[1,m] 的数组，使「从左扫描更新最大值」恰好发生 `k` 次；计数。

## 最优思路

`dp[len][cost][max]`：追加 ≤max 保持 cost；追加更大值 cost+1。前缀和加速。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\cdot m\cdot k)\) |
| 空间 | \(O(m\cdot k)\) |
