# LC 1402. Reducing Dishes

> Hard · [LeetCode](https://leetcode.com/problems/reducing-dishes/) · Tags: Array, Greedy, Sorting

## 题意

做菜满意度与时间相乘求和最大；可不做某些菜。

## 最优思路

排序后从大到小累加：每多加一道菜，相当于已有和再 +1 时间系数。

## 图解

```text
… + add dish → sum += prefix_of_chosen
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log n)\) |
| 空间 | \(O(1)\) |
