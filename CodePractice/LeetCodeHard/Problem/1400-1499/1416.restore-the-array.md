# LC 1416. Restore The Array

> Hard · [LeetCode](https://leetcode.com/problems/restore-the-array/) · Tags: String, Dynamic Programming

## 题意

把数字串拆成若干 ∈[1,k] 的整数（无前导零），求方案数。

## 最优思路

`dp[i]`：从下标 `i` 起的方案数；枚举结尾，数值 ≤k 则累加 `dp[j+1]`。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log k)\) |
| 空间 | \(O(n)\) |
