# LC 1406. Stone Game III

> Hard · [LeetCode](https://leetcode.com/problems/stone-game-iii/) · Tags: DP, Game Theory

## 题意

两人轮流取 1–3 堆石子，求最优下 Alice/Bob/Tie。

## 最优思路

`dp[i]` = 从 `i` 开始先手相对后手的最优分差；取 `k` 堆后为 `sum - dp[i+k]`。

## 图解

```text
dp[i] = max_k (sum(i..i+k-1) - dp[i+k])
```
