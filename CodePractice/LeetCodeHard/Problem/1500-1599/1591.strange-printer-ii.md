# LC 1591. Strange Printer II

> Hard · [LeetCode](https://leetcode.com/problems/strange-printer-ii/) · Tags: Graph, Topological Sort

## 题意

打印机每次把矩形刷成同色；判断 `targetGrid` 能否由空网格打印得到。

## 最优思路

每种颜色的出现必成矩形；矩形内异色表示异色更晚打印 → 建边拓扑判环。

## 图解

```text
color c 包围盒内的 d → c 先于 d
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(C\cdot mn)\) |
| 空间 | \(O(C^2)\) |
