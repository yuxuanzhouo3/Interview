# LC 1585. Check If String Is Transformable With Substring Sort Operations

> Hard · [LeetCode](https://leetcode.com/problems/check-if-string-is-transformable-with-substring-sort-operations/) · Tags: String, Greedy

## 题意

可对任意子串排序，判断 `s` 能否变成 `t`。

## 最优思路

排序=冒泡，数字只能与更大者交换左移。对 `t` 逐位取 `s` 中对应数字，确保左侧无更小数字挡住。

## 图解

```text
t 的每位 ← s 中该数字最早可用下标，且左侧无更小 digit
```

## 复杂度

| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
