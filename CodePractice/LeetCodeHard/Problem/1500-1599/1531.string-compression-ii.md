# LC 1531. String Compression II

> Hard · [LeetCode](https://leetcode.com/problems/string-compression-ii/) · Tags: String, Dynamic Programming

## 题意

可删至多 `k` 字符后按 run-length 压缩，求最短压缩长度。

## 最优思路

记忆化：从 `i` 起，删或不删；保留时把后续同字符收进同一 run，异字符计入删除。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2 k)\) |
| 空间 | \(O(nk)\) |
