# LC 1553. Minimum Number of Days to Eat N Oranges

> Hard · [LeetCode](https://leetcode.com/problems/minimum-number-of-days-to-eat-n-oranges/) · Tags: DP, Memoization

## 题意

每天吃 1 个，或在偶数时吃一半，或在 3 的倍数时吃 2/3，求吃完最少天数。

## 最优思路

记忆化：先吃 `x%2` / `x%3` 个到达可整除点，再递归 `x//2`、`x//3`。

## 图解

```text
n → n%2 + n/2  or  n%3 + n/3
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(\log n)\) 量级 |
| 空间 | \(O(\log n)\) |
