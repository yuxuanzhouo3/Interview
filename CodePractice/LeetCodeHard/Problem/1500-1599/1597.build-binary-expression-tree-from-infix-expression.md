# LC 1597. Build Binary Expression Tree From Infix Expression

> Hard · [LeetCode](https://leetcode.com/problems/build-binary-expression-tree-from-infix-expression/) · Premium · Tags: Stack, Tree

## 题意

中缀表达式（含括号、四则）建成二叉表达式树。

## 最优思路

操作数栈 + 运算符栈，按优先级弹出建内部节点。

## 图解

```text
3*4-2 → 先建 * 子树再挂到 -
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | O(n) |
| 空间 | O(n) |
