# LC 1520. Maximum Number of Non-Overlapping Substrings

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-non-overlapping-substrings/) · Tags: Greedy, String

## 题意

选尽可能多的不相交子串，使得每个子串包含其中每个字符在全串中的全部出现。

## 最优思路

对每个字符扩展为合法闭包区间，按右端点贪心选取。

## 图解

```text
字符区间闭包 → 区间调度（最早结束）
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(1)\) |
