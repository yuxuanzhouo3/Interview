# LC 2543. Check if Point is Reachable

> Hard · [LeetCode](https://leetcode.com/problems/check-if-point-is-reachable/) · Tags: Math, Number Theory

## 题意

从 `(1,1)` 经 `(x,y)→(x+y,y)` 或 `(x,x+y)`，以及任意时刻两边同时除 2（若均为偶），能否到目标。

## 最优思路

逆向：奇偶约化后 gcd 必须为 2 的幂。

## 图解

```text
reachable ⇔ gcd(x,y) is power of 2
```
