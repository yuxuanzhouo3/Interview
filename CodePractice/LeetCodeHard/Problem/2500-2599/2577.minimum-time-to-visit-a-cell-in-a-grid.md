# LC 2577. Minimum Time to Visit a Cell In a Grid

> Hard · [LeetCode](https://leetcode.com/problems/minimum-time-to-visit-a-cell-in-a-grid/) · Tags: Dijkstra, Matrix

## 题意

时刻 `t` 只能进入 `grid[i][j] ≤ t` 的格子；每步耗时 1，可来回等待；求到右下最短时间。

## 最优思路

若开局两邻格都 >1 则无解。Dijkstra；若目标要求更大时刻，用偶/奇等待保持到达时刻奇偶合法。

## 图解

```text
need wait = grid[ni][nj]-(t+1); if odd +=1 (bounce)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(mn\log mn)\) |
| 空间 | \(O(mn)\) |
