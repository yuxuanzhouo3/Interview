# LC 2514. Count Anagrams

> Hard · [LeetCode](https://leetcode.com/problems/count-anagrams/) · Tags: Math, Combinatorics, String

## 题意

对句子中每个单词做字母重排（单词顺序不变），不同句子数模 \(10^9+7\)。

## 最优思路

每个单词方案 = `n! / Π(cnt[c]!)`，总答案为各单词方案之积。

## 图解

```text
multinomial(word) × … × multinomial(word)
```

## 复杂度

| 时间 | \(O(L)\) |
| 空间 | \(O(L)\) |
