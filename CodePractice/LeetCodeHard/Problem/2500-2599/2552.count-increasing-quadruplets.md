# LC 2552. Count Increasing Quadruplets

> Hard · [LeetCode](https://leetcode.com/problems/count-increasing-quadruplets/) · Tags: Array, Dynamic Programming, Binary Indexed Tree, Enumeration, Prefix Sum

## 题意

统计 \(i<j<k<l\) 且 `nums[i] < nums[k] < nums[j] < nums[l]` 的四元组个数。

## 最优思路

从左到右枚举 `k`（将来可作为 `l` 或作为更小端）。`dp[j]` 累计满足 `nums[i]<nums[k]<nums[j]` 的 `(i,k)` 数；当 `nums[j]<nums[k]` 时把 `dp[j]` 计入答案（此时 `k` 充当 `l`）。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2)\) |
| 空间 | \(O(n)\) |
