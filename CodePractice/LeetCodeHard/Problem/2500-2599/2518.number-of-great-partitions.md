# LC 2518. Number of Great Partitions

> Hard · [LeetCode](https://leetcode.com/problems/number-of-great-partitions/) · Tags: Array, Dynamic Programming

## 题意

将数组分成两个有序组，每组元素和都 ≥ `k`，求方案数 mod \(10^9+7\)。

## 最优思路

总方案 \(2^n\)。背包 DP 统计子集和 `< k` 的个数 `bad`，答案 = \(2^n - 2\cdot bad\)。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(nk)\) |
| 空间 | \(O(k)\) |
