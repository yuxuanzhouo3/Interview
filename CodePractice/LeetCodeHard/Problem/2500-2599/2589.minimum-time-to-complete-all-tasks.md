# LC 2589. Minimum Time to Complete All Tasks

> Hard · [LeetCode](https://leetcode.com/problems/minimum-time-to-complete-all-tasks/) · Tags: Array, Greedy, Sorting

## 题意

任务需在 `[start,end]` 内开机若干秒；求完成全部任务的最少开机秒数。

## 最优思路

按结束时间排序；对每个任务从右往左补齐尚未覆盖的时长（复用已开机时刻）。

## 图解

```text
sort by end → fill needed seconds from end backwards
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n \cdot T)\) |
| 空间 | \(O(T)\) |
