# LC 2581. Count Number of Possible Root Nodes

> Hard · [LeetCode](https://leetcode.com/problems/count-number-of-possible-root-nodes/) · Tags: Array, Hash Table, Dynamic Programming, Tree, Depth-First Search

## 题意

给定树上猜测有向边；若以某节点为根时猜对 ≥ `k` 条，则该根合法。求合法根个数。

## 最优思路

先算根为 0 的猜对数，再换根：边方向翻转时 ±1。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n+|guesses|)\) |
| 空间 | \(O(n+|guesses|)\) |
