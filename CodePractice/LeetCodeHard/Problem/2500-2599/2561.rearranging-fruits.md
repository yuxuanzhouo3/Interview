# LC 2561. Rearranging Fruits

> Hard · [LeetCode](https://leetcode.com/problems/rearranging-fruits/) · Tags: Array, Greedy, Hash Table

## 题意

交换两篮子水果使频率相等；一次交换代价为 `min(两果)`；可间接经最小果。求最小代价。

## 最优思路

差分计数须偶数；需交换的一半取最小；代价 `min(果, 2·全局最小)`。

## 图解

```text
swap a↔b cost min(a,b); or a↔m↔b cost 2m
```
