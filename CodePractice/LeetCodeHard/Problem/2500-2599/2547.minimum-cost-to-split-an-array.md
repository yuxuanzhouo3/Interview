# LC 2547. Minimum Cost to Split an Array

> Hard · [LeetCode](https://leetcode.com/problems/minimum-cost-to-split-an-array/) · Tags: Array, Hash Table, Dynamic Programming, Counting

## 题意

切分数组，段代价 = `k + trimmed(段)`，求最小总代价。

## 最优思路

`dp[i]` 前 i 个最小代价；枚举最后一段并维护 trimmed。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2)\) |
| 空间 | \(O(n)\) |
