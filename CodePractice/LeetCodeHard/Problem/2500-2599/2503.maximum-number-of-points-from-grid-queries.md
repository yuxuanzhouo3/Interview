# LC 2503. Maximum Number of Points From Grid Queries

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-points-from-grid-queries/) · Tags: Heap, Matrix, Sorting

## 题意

从左上出发，只能进入值 **严格小于** 查询值的格子；每个查询独立求可达格数。

## 最优思路

查询升序；用最小堆扩展「边界」格子，把值 < 当前查询的全部弹出计入答案，后续查询继承状态。

## 图解

```text
sort queries ↑
heap frontier by cell value
pop while value < q → +points
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(mn\log mn + q\log q)\) |
| 空间 | \(O(mn)\) |
