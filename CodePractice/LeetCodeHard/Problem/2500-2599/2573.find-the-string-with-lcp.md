# LC 2573. Find the String with LCP

> Hard · [LeetCode](https://leetcode.com/problems/find-the-string-with-lcp/) · Tags: Array, String, Dynamic Programming, Greedy, Union-Find, Matrix

## 题意

给定 LCP 矩阵，构造字典序最小字符串；不可能则 `""`。

## 最优思路

`lcp[i][j]>0` 则 `s[i]==s[j]`，贪心按字母赋值；再按 LCP 递推关系验证。

## 图解

```text
lcp[i][j]=lcp[i+1][j+1]+1 当 s[i]==s[j]
否则 lcp 必为 0
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2)\) |
| 空间 | \(O(n)\) |
