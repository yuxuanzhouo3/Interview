# LC 827. Making A Large Island

> Hard · [LeetCode](https://leetcode.com/problems/making-a-large-island/)

## 题意

最多把一个 0 改成 1，求最大岛面积。

## 最优思路

先标岛算面积；枚举每个 0，合并相邻不同岛。

## 图解

```text
label islands → flip 0 → sum unique neighbor areas + 1
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2)\) |
| 空间 | \(O(n^2)\) |
