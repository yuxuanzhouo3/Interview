# LC 882. Reachable Nodes In Subdivided Graph

> Hard · [LeetCode](https://leetcode.com/problems/reachable-nodes-in-subdivided-graph/) · Tags: Graph, Heap, Dijkstra

## 题意

边 `[u,v,cnt]` 被细分为 \(cnt\) 个新节点。从 0 出发最多走 `maxMoves` 步，求可达节点总数（含原节点与细分点）。

## 最优思路

Dijkstra 求到各原节点的最少步数；对每条边两端剩余步数之和与 \(cnt\) 取 min，累加细分点。

## 图解

```text
0 --(cnt)--+-- v
reachable subdiv = min(cnt, left_u + left_v)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(E\log V)\) |
| 空间 | \(O(V+E)\) |
