# LC 847. Shortest Path Visiting All Nodes

> Hard · [LeetCode](https://leetcode.com/problems/shortest-path-visiting-all-nodes/)

## 题意

无向图最短路径长度（可重复访点）覆盖全部节点。

## 最优思路

状态 BFS `(node, visited_mask)`；全源起步。

## 图解

```mermaid
flowchart LR
  State[u,mask] --> Neighbors
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2 2^n)\) |
| 空间 | \(O(n 2^n)\) |
