# LC 2926. Maximum Balanced Subsequence Sum

> Hard · [LeetCode](https://leetcode.com/problems/maximum-balanced-subsequence-sum/) · Tags: Array, Binary Search, Dynamic Programming, Binary Indexed Tree, Segment Tree

## 题意

子序列平衡条件：对相邻选中下标 \(i_j < i_{j+1}\)，有 `nums[i_j]-i_j <= nums[i_{j+1}]-i_{j+1}`。求平衡子序列最大元素和。

## 最优思路

按 `nums[i]-i` 离散化，树状数组维护前缀最大 DP 值。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log n)\) |
| 空间 | \(O(n)\) |
