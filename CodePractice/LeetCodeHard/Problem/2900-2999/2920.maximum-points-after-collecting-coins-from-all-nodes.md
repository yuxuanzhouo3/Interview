# LC 2920. Maximum Points After Collecting Coins From All Nodes

> Hard · [LeetCode](https://leetcode.com/problems/maximum-points-after-collecting-coins-from-all-nodes/) · Tags: Tree DP

## 题意

树上收集硬币：两种操作——得 `coins-k`，或得 `⌊coins/2⌋` 且整棵未访问子树硬币再 `/2`。

## 最优思路

树 DP：状态为「祖先选了几次 /2」（≤14 足够）；每个节点取两种操作的较大值。

## 图解

```text
dp[u][t] = max( coins>>t - k + Σdp[v][t],
                (coins>>t)//2 + Σdp[v][t+1] )
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log C)\) |
| 空间 | \(O(n\log C)\) |
