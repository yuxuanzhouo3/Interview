# LC 2999. Count the Number of Powerful Integers

> Hard · [LeetCode](https://leetcode.com/problems/count-the-number-of-powerful-integers/) · Tags: Math, String, Dynamic Programming

## 题意

统计 `[start, finish]` 中「强大整数」：数位均 ≤ `limit` 且以字符串 `s` 为后缀。

## 最优思路

按长度分类计数 + 同长度数位限制枚举。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(L^2)\) 量级 |
| 空间 | \(O(L)\) |
