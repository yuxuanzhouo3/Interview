# LC 2969. Minimum Number of Coins for Fruits II

> Hard · [LeetCode](https://leetcode.com/problems/minimum-number-of-coins-for-fruits-ii/) · Tags: Array, Dynamic Programming, Queue, Heap (Priority Queue), Monotonic Queue

## 题意

买第 `i` 个水果花 `prices[i]`，并免费获得后面至多 `i` 个（1-index）。求获得全部最少花费。

## 最优思路

`dp[i]=prices[i]+min(dp[i+1..min(n,2i)])`，单调队列优化。
