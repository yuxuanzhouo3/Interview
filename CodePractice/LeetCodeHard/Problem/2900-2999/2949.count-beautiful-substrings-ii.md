# LC 2949. Count Beautiful Substrings II

> Hard · [LeetCode](https://leetcode.com/problems/count-beautiful-substrings-ii/) · Tags: Hash Table, Math, String, Number Theory, Prefix Sum

## 题意

统计元音数=辅音数且乘积被 k 整除的美丽子串个数。

## 最优思路

平衡前缀 + 使 v^2≡0(mod k) 的最小倍数 m，哈希计数。

## 复杂度

|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
