# LC 2995. Viewers Turned Streamers

> Hard · [LeetCode](https://leetcode.com/problems/viewers-turned-streamers/) · Tags: Database

## 题意

找出首次会话为 Viewer、之后有 Streamer 会话的用户及其 Streamer 会话。

## 最优思路

窗口取首场类型，再连接 Streamer 场次。

## 图解

```mermaid
flowchart LR
  A[首场 Viewer] --> B[后续 Streamer]
  B --> C[排序输出]
```
