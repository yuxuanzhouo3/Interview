# LC 2973. Find Number of Coins to Place in Tree Nodes

> Hard · [LeetCode](https://leetcode.com/problems/find-number-of-coins-to-place-in-tree-nodes/) · Tags: Tree, DFS

## 题意

对每个子树：节点数 <3 放 1 枚；否则放「任选 3 个 cost 乘积」的最大值（若为负则放 0）。

## 最优思路

DFS 收集子树 cost，只保留最小 2 + 最大 3；乘积候选为三最大，或两最小（负）×最大。

## 图解

```text
product = max(a*b*c of top3, min1*min2*max1, 0)
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) （每节点常数极值） |
| 空间 | \(O(n)\) |
