# LC 2972. Count the Number of Incremovable Subarrays II

> Hard · [LeetCode](https://leetcode.com/problems/count-the-number-of-incremovable-subarrays-ii/) · Tags: Array, Two Pointers, Binary Search

## 题意

删一个连续子数组后，剩余（可为空）严格递增；求有多少种删法。

## 最优思路

找最长严格递增前缀/后缀，双指针枚举保留前缀右端与后缀左端。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n)\) |
| 空间 | \(O(1)\) |
