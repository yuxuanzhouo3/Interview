# LC 2991. Top Three Wineries 

> Hard · [LeetCode](https://leetcode.com/problems/top-three-wineries/) · Tags: Database

## 题意

每个国家按积分总和取前三酒庄，格式 `winery (points)`；不足则占位。

## 最优思路

按国家分组求 sum，窗口 `RANK`，再条件聚合。

## 图解

```mermaid
flowchart LR
  A[GROUP BY country,winery] --> B[RANK]
  B --> C[透视 top3]
```

## 复杂度

| 项 | 值 |

| 时间 | \(O(n\log n)\) |
| 空间 | \(O(n)\) |
