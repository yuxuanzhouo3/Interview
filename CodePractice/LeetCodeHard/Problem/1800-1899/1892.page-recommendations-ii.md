# LC 1892. Page Recommendations II

> Hard · [LeetCode](https://leetcode.com/problems/page-recommendations-ii/) · Premium · Tags: Database

## 题意

推荐朋友喜欢但自己未喜欢的页面，并统计朋友点赞数。

## 最优思路

双向展开 Friendship，JOIN Likes，排除自己已赞，GROUP BY 计数。

## 图解

```text
user → friends → pages \ my_likes
```
