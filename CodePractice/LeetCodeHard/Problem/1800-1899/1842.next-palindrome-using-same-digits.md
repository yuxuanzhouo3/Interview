# LC 1842. Next Palindrome Using Same Digits

> Hard · [LeetCode](https://leetcode.com/problems/next-palindrome-using-same-digits/) · Premium · Tags: String, Two Pointers

## 题意

用相同数字重排，求严格更大的下一个回文；不存在返回空串。

## 最优思路

回文由左半决定：对左半做 next_permutation，再镜像拼回（奇数保留中位）。

## 图解

```text
1221 → 左半 12 → next 21 → 2112
32123 → 左半 32 → 无 next → ""
```

## 复杂度

| 时间 | \(O(n)\) |
| 空间 | \(O(n)\) |
