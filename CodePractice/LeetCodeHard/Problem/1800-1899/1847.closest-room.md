# LC 1847. Closest Room

> Hard · [LeetCode](https://leetcode.com/problems/closest-room/) · Tags: Array, Binary Search, Sorting, Ordered Set

## 题意

每个查询找 `size≥minSize` 且 `id` 最接近 `preferred` 的房间（并列取更小 id）。

## 最优思路

房间与查询按 size 降序；指针加入合格房间 id 到有序集，再二分找最接近。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O((n+q)\log n)\) |
| 空间 | \(O(n)\) |
