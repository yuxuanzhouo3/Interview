# LC 1866. Number of Ways to Rearrange Sticks With K Sticks Visible

> Hard · [LeetCode](https://leetcode.com/problems/number-of-ways-to-rearrange-sticks-with-k-sticks-visible/) · Tags: Math, Dynamic Programming, Combinatorics

## 题意

`n` 根不同高度木棍排成一列，从左看恰好 `k` 根可见（更高挡住更矮），求排列数 mod \(10^9+7\)。

## 最优思路

放最高棍：若在最左则必可见 → `dp[n-1][k-1]`；否则在其余 `n-1` 个位置之一且不可见贡献 → `(n-1)*dp[n-1][k]`。

## 图解

```text
dp[i][j] = dp[i-1][j-1] + (i-1)*dp[i-1][j]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(nk)\) |
| 空间 | \(O(nk)\) |
