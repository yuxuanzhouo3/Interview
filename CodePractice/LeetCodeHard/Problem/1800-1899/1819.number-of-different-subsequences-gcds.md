# LC 1819. Number of Different Subsequences GCDs

> Hard · [LeetCode](https://leetcode.com/problems/number-of-different-subsequences-gcds/) · Tags: Array, Math, Counting, Number Theory, GCD

## 题意

求数组所有非空子序列的 GCD 能取到多少个不同值。

## 最优思路

对候选 `g=1..max(nums)`：把出现过的 `g` 的倍数不断取 GCD；若最终等于 `g`，则 `g` 可达。枚举倍数总计 \(O(M\log M)\)。

## 图解

```mermaid
flowchart LR
  G[候选 g] --> M[出现的倍数]
  M --> C["gcd == g?"]

```
