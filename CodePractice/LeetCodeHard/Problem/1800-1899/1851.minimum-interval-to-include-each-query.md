# LC 1851. Minimum Interval to Include Each Query

> Hard · [LeetCode](https://leetcode.com/problems/minimum-interval-to-include-each-query/) · Tags: Array, Binary Search, Heap, Sorting

## 题意

对每个查询 `q`，找覆盖 `q` 的区间中长度最短者；无则 `-1`。

## 最优思路

查询与区间按左端/值排序。扫到查询时把所有 `left≤q` 的区间按长度入堆，弹出 `right<q` 的，堆顶长度即答案。

## 图解

```mermaid
flowchart LR
  Q[查询升序] --> A[加入 left≤q 的区间]
  A --> B[弹出 right<q]
  B --> C[堆顶长度]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O((n+q)\log(n+q))\) |
| 空间 | \(O(n+q)\) |
