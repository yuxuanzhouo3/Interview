# LC 3057. Employees Project Allocation

> Hard · [LeetCode](https://leetcode.com/problems/employees-project-allocation/) · Tags: Database

## 题意

找出个人总工作量高于团队平均工作量的员工及其项目明细。

## 最优思路

窗口求个人总量与团队均值，再过滤。

## 图解

```mermaid
flowchart LR
  A[JOIN] --> B[窗口聚合]
  B --> C[过滤 emp_load > team_avg]
```
