# LC 3060. User Activities within Time Bounds

> Hard · [LeetCode](https://leetcode.com/problems/user-activities-within-time-bounds/) · Tags: Database

## 题意

同一用户同类型两次会话间隔 ≤ 该类型时限，则输出用户。

## 最优思路

同用户同类型会话排序，双指针 / 自连接检查间隔。

## 图解

```mermaid
flowchart LR
  A[按用户类型分组] --> B[检查相邻间隔]
  B --> C[去重用户]
```

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n\log n)\) |
| 空间 | \(O(n)\) |
