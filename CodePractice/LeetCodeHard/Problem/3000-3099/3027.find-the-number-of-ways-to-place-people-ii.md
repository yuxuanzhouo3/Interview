# LC 3027. Find the Number of Ways to Place People II

> Hard · [LeetCode](https://leetcode.com/problems/find-the-number-of-ways-to-place-people-ii/) · Tags: Geometry, Sorting, Enumeration

## 题意

选两点 A 左上、B 右下，矩形内（含边界）无其它点；求方案数。

## 最优思路

按 x 升、y 降排序；对每个左点向右扫，维护已见最大 y 下界，合法则计数。

## 图解

```text
  ····B   no points inside rectangle
```
