# LC 3045. Count Prefix and Suffix Pairs II

> Hard · [LeetCode](https://leetcode.com/problems/count-prefix-and-suffix-pairs-ii/) · Tags: Array, String, Trie, Rolling Hash, String Matching, Hash Function, Z Algorithm

## 题意

统计满足 words[i] 同时是 words[j] 的前缀与后缀的下标对 (i,j) i<j。

## 最优思路

按 (首,尾) 字符对建 Trie，途经节点计数。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(\sum|w|)\) |
| 空间 | \(O(\sum|w|)\) |
