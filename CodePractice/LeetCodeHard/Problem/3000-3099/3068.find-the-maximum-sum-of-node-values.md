# LC 3068. Find the Maximum Sum of Node Values

> Hard · [LeetCode](https://leetcode.com/problems/find-the-maximum-sum-of-node-values/) · Tags: Greedy, Bit Manipulation, Tree

## 题意

树上选边操作：两端点都异或 `k`；可多次。求节点值之和最大。

## 最优思路

等价于偶数个节点异或 `k`。按增益排序，成对累加正收益。

## 图解

```text
gain[i]=(nums[i]^k)-nums[i]; take best even-sized subset
```

| 空间 | \(O(n)\) |
