# LC 3036. Number of Subarrays That Match a Pattern II

> Hard · [LeetCode](https://leetcode.com/problems/number-of-subarrays-that-match-a-pattern-ii/) · Tags: Array, Rolling Hash, String Matching, Hash Function

## 题意

`pattern` 匹配相邻比较关系（1/>、0/=、-1/<）；统计 `nums` 中匹配的子数组个数。

## 最优思路

把 `nums` 差分关系映射成序列，KMP 计数。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n+m)\) |
| 空间 | \(O(n+m)\) |
