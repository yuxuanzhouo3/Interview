# LC 3018. Maximum Number of Removal Queries That Can Be Processed I

> Hard · [LeetCode](https://leetcode.com/problems/maximum-number-of-removal-queries-that-can-be-processed-i/) · Tags: Array, Dynamic Programming

## 题意

可先把 `nums` 换成其子序列；之后每次只能删两端之一且需 ≥ 当前 query。求最多能处理多少 query。

## 最优思路

剩余始终是原数组的连续区间 `[i,j]`。`f[i][j]` 表示该区间尚未删完时已处理的 query 数，由删去 `i-1` 或 `j+1` 转移；最后再对单点补一次。

## 复杂度

| 项 | 值 |
|----|----|
| 时间 | \(O(n^2)\) |
| 空间 | \(O(n^2)\) |
