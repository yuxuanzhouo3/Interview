# LC 4091. Count Magical Substring Pairs II

> Hard · [LeetCode](https://leetcode.com/problems/count-magical-substring-pairs-ii/) · Tags: 

## 题意

给你一个长度为 n 且仅由小写英文字母组成的字符串 s。 对于满足 0 <= i <= j < k < n 的每一个下标三元组 (i, j, k)，定义： s1 = s[i..j] s2 = s[j + 1..k] 如果 s1 中不同字符的数量等于 s2 中不同字符的数量，则称这对子字符串 (s1, s2) 是神奇的。 返回满足 (s1, s2) 是神奇对的三元组 (i, j, k) 的数量。 子字符串是字符串中连续的非空字符序列。 示例 1： 输入： s = "aba" 输出： 2 解释： 有 2 个有效的三元组…
