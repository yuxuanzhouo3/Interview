# LC 4051. Count Subarrays with Distant Sums

> Hard · [LeetCode](https://leetcode.com/problems/count-subarrays-with-distant-sums/) · Tags: Array, Binary Search, Binary Indexed Tree, Segment Tree, Prefix Sum

## 题意

给你一个整数数组 nums ，以及两个整数 goal 和 k 。 如果一个 子数组 nums[i..j] 满足其元素和与 goal 之间的 绝对差至少 为 k ，则称其为 遥远的 。 返回 遥远的 子数组的数量。 子数组 是数组中连续的非空元素序列。 示例 1： 输入： nums = [1,2,1], goal = 4, k = 1 输出： 5 解释： 对于 k = 1 ，遥远的子数组为： i j nums[i..j] 元素和 abs(sum - goal) 0 0 [1] 1 3 1 1 [2] 2 2 2 2…
