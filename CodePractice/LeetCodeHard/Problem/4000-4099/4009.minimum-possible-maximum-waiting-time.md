# LC 4009. Minimum Possible Maximum Waiting Time

> Hard · [LeetCode](https://leetcode.com/problems/minimum-possible-maximum-waiting-time/) · Tags: Array, Dynamic Programming, Memoization

## 题意

两台加油机有限油量，按顺序服务车辆；先最大化服务前缀，再最小化这些车上的最大等待时间。

## 最优思路

状态压缩两台剩余油量与相对空闲时间，逐车转移并记录当前前缀最大等待的最小值。

```text
输入 → 关键建模 → 最优算法 → 答案
```
