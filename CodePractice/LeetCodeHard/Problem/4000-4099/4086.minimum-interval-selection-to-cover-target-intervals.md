# LC 4086. Minimum Interval Selection to Cover Target Intervals

> Hard · [LeetCode](https://leetcode.com/problems/minimum-interval-selection-to-cover-target-intervals/) · Tags: 

## 题意

给你两个二维整数数组 availableIntervals 和 targetIntervals，每个数组都表示一系列 闭区间。 从 availableIntervals 中选择一个 子集，使得 targetIntervals 中任何区间包含的 每一个实数点 都属于至少一个被选中的区间。 目标区间之外的点不需要被覆盖。选中的区间可以相互重叠，也可以延伸到目标区间之外。 返回你需要选择的 最小 区间数量。如果无法覆盖所有的目标区间，返回 -1。 数组的 子集 是指从该数组中选择的一些元素（可能不选择任何元素）组成的集合…
