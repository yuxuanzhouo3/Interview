# LC 4073. Count Good Strings

> Hard · [LeetCode](https://leetcode.com/problems/count-good-strings/) · Tags: —

## 题意

只含 a/b 的好串：要么奇数长单字符，要么两个好串拼接且接缝字符不同。求长度 n 的好串数模 1e9+7（n≤1e15）。

## 最优思路

好串 ⟺ 奇数长交替单字符块的拼接。奇数分拆数是 Fibonacci，乘起始字母 2 种；矩阵快速幂。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```
