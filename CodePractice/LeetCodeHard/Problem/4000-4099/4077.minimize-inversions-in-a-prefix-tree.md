# LC 4077. Minimize Inversions in a Prefix Tree

> Hard · [LeetCode](https://leetcode.com/problems/minimize-inversions-in-a-prefix-tree/) · Tags: —

## 题意

给你一个包含 n 个 互不相同 字符串的数组 words ，这些字符串仅由从 'a' 到 'j' 的小写英文字母组成。另给你一个整数数组 target ，其中每个从 0 到 n - 1 的下标都恰好出现一次。 利用 words 构建一棵 前缀树 ： 根节点表示空字符串 "" 。 每个其他节点表示单词中一个不同的非空前缀。一个节点的父节点是通过移除其最后一个字符后得到的前缀。 表示完整单词 words[i] 的节点被标记为下标 i 。被标记的节点也可以拥有子节点。 你可以 独立地 选择 每个节点 内子节点的访问顺序。但不能改变哪个节点是子节点的父节点…
