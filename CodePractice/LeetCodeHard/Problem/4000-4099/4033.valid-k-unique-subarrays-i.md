# LC 4033. Valid K-Unique Subarrays I

> Hard · [LeetCode](https://leetcode.com/problems/valid-k-unique-subarrays-i/) · Tags: Array, Hash Table, Bit Manipulation, Binary Indexed Tree, Segment Tree, Sliding Window, Hash Function, Prefix Sum

## 题意

询问子数组是否恰好 k 个不同数且每个出现偶数次。

## 最优思路

前缀随机 XOR 可快速排除非全偶；再统计不同个数与奇偶确认。
