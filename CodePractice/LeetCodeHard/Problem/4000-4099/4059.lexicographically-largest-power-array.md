# LC 4059. Lexicographically Largest Power Array

> Hard · [LeetCode](https://leetcode.com/problems/lexicographically-largest-power-array/) · Tags: Array, Greedy, Bit Manipulation

## 题意

重排 nums 得到 perm，对每个比特位统计「前缀中该位全为 1」的最长长度，组成长度 15 的 power，求字典序最大的 power。

## 最优思路

从高位到低位字典序优先：把数值从大到小排序即可让高位 1 尽量靠前，再逐位扫描前缀长度。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```
