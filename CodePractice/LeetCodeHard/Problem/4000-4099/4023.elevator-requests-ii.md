# LC 4023. Elevator Requests II

> Hard · [LeetCode](https://leetcode.com/problems/elevator-requests-ii/) · Tags: Array, Dynamic Programming, Sorting

## 题意

电梯从 start 出发服务所有请求楼层，每秒移动一层；未完成请求每秒罚 1，求最小总罚时。

## 最优思路

最优轨迹是覆盖请求区间的左右扩展。区间 DP：当前覆盖 [L,R]、停在左/右端，扩展时乘以剩余请求数。

## 图解

```text
输入 → 关键建模 → 最优算法 → 答案
```
