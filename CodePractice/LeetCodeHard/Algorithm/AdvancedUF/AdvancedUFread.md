# AdvancedUF · Syllabus

数据结构底板见 `DataStructure/AdvancedGraph/union_find.py`。本目录聚焦 **Hard 并查集算法范式**：加权、离线、撤销、网格/图应用。

## 学习路径

```
基础 DSU → 按大小/秩 + 连通分量属性
  → 网格/边离线合并 → 加权/扩展域
  → 可撤销 / 分治回滚 → Hard 连通题套餐
```

## 何时用 UF，何时 DFS/BFS

| 场景 | 选 |
|------|----|
| 在线合并、反复问是否同分量 | DSU |
| 一次性遍历连通块、要路径本身 | DFS/BFS |
| 边按条件逐步「激活」 | 离线排序 + DSU |
| 需要删边且多次回溯 | 可撤销 DSU / 分治 |
| 相对距离、奇偶、敌友 | 带权 / 扩展域 |

## 面试口述 checklist

1. 路径压缩 + 按秩，均摊几乎 O(1)。
2. 要 `undo` 时不要路径压缩，只按秩，用栈记修改。
3. 网格：坐标压成一维；障碍格不要 `add` 进集合。
4. 「删边」常改写成离线倒序「加边」。
5. 带权：维护到父节点的关系，`find` 时顺带更新权。
