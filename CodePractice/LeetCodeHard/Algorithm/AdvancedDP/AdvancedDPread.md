# AdvancedDP · Syllabus

对照：`CodePractice/dp.py` / `dp.py` 八大类 + Hard 进阶。统一写法：明确状态 → 转移 → 边界；难递推时用记忆化 DFS。

## 学习路径

```
背包 / 线性 → 子序列 → 划分 → 区间
  → 状压 → 树形 → 数位 / 计数
  → 记忆化 DFS → 斜率/Knuth/单调队列优化
```

## Hard 怎么选模板

| 题感 | 优先开 |
|------|--------|
| 最后一步是「切一段 / 合并两段」 | `interval_dp` / `partition_dp` |
| n≤20 且与子集/访问集合有关 | `bitmask_dp` |
| 树、父子互斥或路径汇合 | `tree_dp` |
| 容量/能否凑成 | `knapsack` |
| 递推难写、状态自然是搜索 | `memo_dfs` |
| n 大且决策满足凸性/四边形 | `dp_optimize` |

## 面试口述 checklist

1. 先说状态含义与维度，再说转移与边界，最后复杂度。
2. 区间 DP：外层长度、中层左端点、内层分割点。
3. 状压：集合枚举常用 `sub = (sub - 1) & mask`。
4. 0-1 背包一维必须逆序；完全背包正序。
5. Hard 正则/通配（10/44）优先记忆化或二维匹配 DP。
